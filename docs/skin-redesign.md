# 皮肤重设计（项目记录）

这次重设计把六套皮肤统一为“对话优先”：正文、姓名、引用和继续提示稳定；材质、构图和少量动效表达主题。此页记录设计决策与验证，不是新的扩展 API。资源来源与许可见[装饰来源](skin-art-sources.md)，实现方向见[程序版画](skin-art-direction.md)。

## 已确定的结构

- 六套皮肤共用同一对话布局、字号层级、边距和可访问性规则。
- 主题差异集中在框体、背景材质、装饰插图、色彩和克制的 GPU 动效。
- 对话框使用九宫格或透明表面；装饰绘制不改变文本布局，也不遮挡输入和继续操作。
- 动效采用 16 秒循环；减少动态或 GPU 失败时，回退为固定 `still.png`。
- 每套皮肤只有一个 artwork shader、一张透明纹理，不能增加自定义运行权限或任意网络/文件访问。

## 设计检查

| 检查 | 验收标准 |
| --- | --- |
| 阅读性 | 正文与背景保持对比度；长文本不依赖颜色单独传达信息 |
| 状态 | 说话人、引用、等待、暂停、错误和继续状态在六套皮肤中语义一致 |
| 动效 | 姿态和光线变化不移动正文；进入/退出可在中途取消并恢复 |
| 性能 | 静止状态按需刷新；动态 GPU P95 记录并与 64MiB 缓存预算比较 |
| 回退 | 编辑器、缩略图、减少动态、编译失败都可显示静态画面 |
| 许可 | 仓库只分发重绘 SVG/PNG/WGSL，馆藏原图不进入构建包 |

## 验证记录

在 1×、1.5×、2× DPI 和中文长文本下检查布局、换行、滚动、历史、输入与继续提示；再分别验证窗口、离屏输出和静态回退。性能报告必须写明源码 revision、设备、后端、负载、预热和统计口径；不要把固定机器的毫秒数当成跨平台承诺。
