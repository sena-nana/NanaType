# 使い方ガイド

日々の操作、配信プラットフォームと OBS への接続、オンライン接続、スタンプ、スキンについての説明です。機能の概要は [README](../../README.ja.md) をご覧ください。

## 基本操作

1. 起動すると入力ウィンドウが画面下部に表示され、以後は動かした位置とサイズを記憶します。入力ウィンドウを閉じるとトレイに隠れ、下書きは残ります。F8 で再び呼び出せます。表示ウィンドウと履歴ウィンドウは透明なオーバーレイです。
2. 入力ウィンドウにそのままセリフを打ち、**Enter** で送信します（Shift+Enter で改行。設定で Ctrl+Enter 送信に変更できます）。Ctrl+↑ / ↓ で送信済みのセリフを呼び戻し、Esc で隠します。
3. 文字を選択してツールバー（または Ctrl+B / I / U）で太字、色、縁取り、ルビ、エフェクト、リズムを付けます。何も選択していないときは、その後に打つ文字に適用されます。ポーズ、改ページ、効果音、表情などのマーカーは文字の間に細い縦線で表示され、レイアウト幅を取らないため、入力ウィンドウと表示ウィンドウの折り返しは完全に一致します。
4. ツールバーの `</>` ボタンでマークアップのソース表示に切り替わります。どちらも同じセリフを編集しています。
5. グローバルホットキー：**F8** で入力ウィンドウを呼び出し、**F9** で続行（ポーズを越える／現在の段落をスキップ）。
6. トレイメニューから各ウィンドウの表示／非表示、オーバーレイのロック、モードとスキンの切り替え、設定を開くことができます。トレイアイコン自体も状態を表します。ミラー中はピンクの丸、表示ウィンドウと履歴が両方隠れているとグレー、オーバーレイがロック中は小さな鍵が付きます。

表示ウィンドウ、接続相手の表示枠、履歴ウィンドウは左ドラッグで移動、ホイールで縦横比を保って拡大縮小できます。右クリックメニューからウィンドウを閉じる、全体のスキンを切り替える／スキン調整を開く、**最前面に表示** の切り替え、**ウィンドウをロック**、**位置とサイズを初期状態に戻す** が使えます。自分の表示ウィンドウでは続行、再生中のスキップ、表示のクリアもでき、履歴ウィンドウではアバター・名前・時刻の表示切り替えと、**履歴を消去 › クリアを確定** による今回の履歴の消去ができます（オンライン接続中は使えません）。ロックするとマウス操作が透過します。解除はトレイか **設定 › ウィンドウ** から行います。ウィンドウを閉じても隠れるだけで、有効な Spout2／Syphon 出力は動き続けます。ネイティブの右クリックメニューが共有テクスチャ出力に映り込むことはありません。

入力モード：

どちらの編集モードもホイール／トラックパッドのスクロールと PageUp／PageDown による移動に対応し、Shift で選択範囲を広げられます。右クリックメニューには元に戻す、やり直し、切り取り、コピー、貼り付け、すべて選択があります。IME で変換中は、Enter、Esc、矢印キーが IME に優先して渡されます。

- **編集して送信**：書き終えてから送信し、表示ウィンドウがタイプライターのリズムで再生します。
- **ミラー（リアルタイム）**：表示ウィンドウが入力をリアルタイムに追いかけ、送信するとセリフが履歴に入ります。

### Twitch チャットとセリフの送信

1. **設定 › Twitch** を開き、チャンネル名か `https://www.twitch.tv/チャンネル名` を入力して **チャットを受信** をオンにします。チャットの読み取りにログインは不要です。
2. セリフを送信するには **Twitch でログイン** をクリックし、twitch.tv/activate を開いてページに表示されたコードを入力します。トークンは OS の保護ストレージ（Windows DPAPI／macOS キーチェーン）に保存されます。
3. **セリフを Twitch チャットに送信** をオンにして確認すると、以後送信したセリフがあなたとしてチャンネルに投稿されます。長いセリフは 500 文字ごとに分割され、失敗したときはキューが一時停止し、再試行かスキップを待ちます。

プロトコル、ログイン、レート制限の詳細は [Twitch 連携](twitch.md) を参照してください。

### 外部コメント：blivechat と彗星号

**設定 › 外部コメント** を開き、オンにしてソースを選びます。

- **blivechat**：blivechat を起動し（既定は `127.0.0.1:12450`）、bilibili オープンプラットフォームの認証コードを入力して **保存して接続** をクリックするか、ルーム番号を使います。認証コードは OS の保護ストレージ（Windows DPAPI／macOS キーチェーン）に保存され、設定ファイルには書き込まれません。
- **彗星号**：彗星号のキャンバスに NanaType プラグインを追加し、設定ページに表示される接続アドレスをプラグイン設定に貼り付けます。プラグインページは [`integrations/comet/`](../../integrations/comet/) にあります。アップロード方法と仕組みは [彗星号連携](comet.md) を参照してください。

外部コメントはコメントパネルに表示され、@、返信、履歴への混在も同じように使えます。配信ルームがない場合は、モックサーバーで blivechat モードを試せます。

```bash
cargo run -p nanatype-blive --example mock_blivechat
```

彗星号モードでは、プラグインページの代わりにスクリプトでサンプルメッセージを中継に送れます（Node 22 以上が必要）。

```bash
node scripts/comet_publish.mjs "ws://127.0.0.1:12451/comet?token=…"
```

### オンライン接続

1. Steam が起動している必要があります。入力ウィンドウ下部のバーから接続の入口を開き、ホストが **接続を作成** をクリックします。ルームは最大 8 人で、パスワードも設定できます。パスワードは招待には含まれません。
2. **フレンドを招待** で Steam の招待が開きます。招待されたフレンドはパスワード入力が不要です。コピーした招待を他の人に渡した場合、ルームがロックされていれば参加前にパスワード入力が必要です。
3. **表示ウィンドウ** には常に自分の内容が表示されます。**接続相手の表示枠** は着席順に他の各メンバーへリアルタイムのセリフ枠を割り当て、まだ誰も入っていないときは招待と承諾状況を表示します。共有履歴には、ホストが確定した順序で全員の送信内容が入ります。スキンとウィンドウ配置は各自のものが保たれます。ミラーでは入力中の内容が公開され、編集して送信では送信済みの内容だけが公開されます。F9、スキップ、表示のクリアは自分にだけ作用します。
4. 接続中、履歴ウィンドウには今回のセッションのセリフが表示されます。接続前の履歴や配信ルームのコメントは共有されません。退出するとローカルの履歴に戻ります。セッションはプロセスを再起動すると復元されません。セッションは直近 1000 件までのセリフを保持し、メッセージサイズの上限に応じてさらに切り詰められます。
5. 切断中も編集はできますが、送信と手動の再生操作は一時停止します。切断すると席は空きますが、空席があれば同じ人が再接続でき、送信済みのセリフは残ります。ホストが退出するとルームは終了します。

画像、スタンプ、アバター、引用内のアバター、現在の立ち絵はコンテンツハッシュで配布されます。プレビューはホストが中継し、完全な画像は投稿者から直接取得し、直接接続に失敗したときはホストに求めます。1 リソースの上限は 16 MiB で、超過や欠落時はプレースホルダーを表示します。ローカルの VTube Studio／OSC などのキャラクター操作をトリガーするのは自分のセリフだけです。

Steam が直接接続できれば直接、できなければ Steam のリレーを経由します。直接接続の場合、相手からネットワークアドレスが見えます。

### OBS への接続

- **Spout2**：**設定 › 出力 / OBS** で Spout2 出力をオンにします。OBS に Spout2 プラグインを入れて *Spout2 Capture* を追加し、送信元名（既定は `NanaType Display` / `NanaType Partner` / `NanaType History`）を選び、合成モードを *Premultiplied Alpha* にします。
- **個別出力**：**設定 › 出力 / OBS** で **表示ウィンドウ** と **接続相手の表示枠** をそれぞれ有効にし、OBS でソースを 2 つ追加して、`NanaType Display`（自分）と `NanaType Partner`（相手）を選びます。サイズ、不透明度、送信元名は個別に設定でき、有効な送信元名は互いに重複できません。相手側の出力は接続中のみ動作し、接続中はウィンドウを隠しても出力し続けます。共有履歴は `NanaType History` を選びます。
- **ウィンドウキャプチャ**：*Window Capture* で、キャプチャ方法に *Windows 10 (1903 and up)* を選びます。
- **Syphon**（macOS）：**設定 › 出力 / OBS** で Syphon 出力をオンにします。OBS に *Syphon Client* を追加し、送信元名（既定は `NanaType Display` / `NanaType Partner` / `NanaType History`）を選び、合成モードを *Premultiplied Alpha* にします。*macOS Screen Capture* で表示ウィンドウをキャプチャすることもできます。Spout2 は Windows 専用です。

出力をオフにして 5 秒以内にオンに戻すと元の送信元が再利用され、OBS の映像は中央値で約 15〜30 ms で戻ります。送信元のライフサイクルと実際の OBS での計測は [OBS / Spout 出力](obs-spout.md) を参照してください。

### 履歴の保存と検索

- **自動保存**：送信したセリフ（オンライン接続中は相手のセリフも）は、初期設定でデータフォルダの `history/` に配信ごとに 1 つの JSON Lines ファイル（例：`2026-11-02_213005.jsonl`）として 1 行ずつ追記されます。クラッシュしても失うのは書き込み中の 1 行までです。視聴者のコメントは **設定 › 履歴 › 履歴の保存 › 視聴者のコメントも保存** をオンにしたときだけ（初期設定はオフ）、履歴に入ったものだけ保存されます。**保存期間（日）** は初期設定で 30 日で、起動時にそれより古い記録を削除します。0 で無期限です。**履歴を消去** はウィンドウの履歴だけを消し、保存ファイルは削除しません。
- **表示と書き出し**：**設定 › 履歴 › 保存した記録** に各回の開始時刻と行数が並びます。**表示** でその回のセリフ（時刻 · 名前 · 内容）を確認し、`.txt` で、または `.srt` 字幕で書き出せます。字幕はその回の最初のセリフを 0 秒とし、各行を次の行が始まるまで、または文字数から見積もった読み時間だけ表示します。**削除** は確認のうえその回のファイルを削除し、**フォルダを開く** で保存場所を開きます。
- **検索**：履歴ウィンドウがロックされていないとき、右上の検索ボタンが入力欄に開き、内容または名前で絞り込みます（大文字小文字を区別しません）。もう一度ボタンを押すか Esc で閉じて絞り込みを解除します。履歴ウィンドウの Spout2／Syphon 出力がオンの間は検索できず、出力には常にすべての履歴が映ります。

### アップデートの確認

Steam 版は Steam が更新するため、この項目はありません。GitHub 版は **設定 › 情報** で GitHub Release の新しいバージョンを確認でき、**設定 › 一般 › アップデート** では既定で 1 日 1 回自動確認します。新しいインストーラーは検証に通ってから開かれます。ダウンロードは GitHub と内蔵プロキシ（gh-proxy.com、ghfast.top、ghproxy.net）を同時に試し、カスタムプロキシを 1 つ追加することもできます。プロキシは転送のみを担い、バージョンマニフェストには Ed25519 署名があり、インストーラーは SHA-256 で検証されます。詳しくは [アップデートの確認](updates.md) を参照してください。

## セリフのマークアップ

セリフは BBCode 風のマークアップで保存され、ソースモード、定型文、テンプレートで共通です。詳しくは [セリフのマークアップ](markup.md) を参照してください。

```text
[@auto=1500]大家好！[wait=400][b][color=#e86a92]今天[/color][/b]也来[wave]打字[/wave]啦～
[pause][shake amp=2]哇！[/shake][se=coin][expr=smile]
[ruby=かんじ]漢字[/ruby][sticker=cats/hello h=1.6]
```

## スタンプ

**設定 › 素材 › スタンプ** では、「羊のピクセルアバター（静止画）」と「羊のアニメーションスタンプ」のプリセットをダウンロードできるほか、ローカルの画像フォルダ、Echo-Live のルートフォルダ（`res/data/emoji.js` を含む）、Echo-Live のスタンプ拡張フォルダ（`main.js` を含む）を追加できます。プリセットはクリックしたときだけネットからダウンロードし、その後はローカルフォルダと同じ取り込み・管理の流れになります。

取り込み時には、画像、サムネイル、GIF の全フレームキャッシュをバックグラウンドで準備し、一覧にダウンロード中・処理中・使用可能・失敗の状態を表示します。完了後はオフラインで使え、元ファイルは変更されず、変化のない内容は再起動後もキャッシュを再利用します。画像や表情定義を変更すると該当キャッシュが自動で再構築されます。削除は読み込みをやめるだけで、元ファイルは消しません。

入力ウィンドウのスタンプパネルで名前やパック名を検索してクリックすると挿入され、`[sticker=sp/happy h=1.35]` や `[sticker=sprel/laugh h=4]` のような NanaType のマークアップとして保存されます。アニメーションスタンプはプレビュー、表示、履歴、Spout／Syphon 出力で再生され、動きを減らす設定では最初のフレームを表示します。この機能は Echo-Live の画像スタンプ定義を読むだけで、拡張スクリプトは実行しません。

入力ウィンドウ右側のスタンプ欄には、下部に「すべて」とシリーズ別のサブタブがあり、スタンプのグリッドは単独でスクロールし、検索は現在のシリーズだけを絞り込みます。1 つ以上のフォルダをスタンプ欄か上部のスタンプタブにドラッグすると素早く追加できます。タブにドロップすると欄が自動で開き、取り込んだものは設定ページと一緒に管理されます。

プリセット画像は [Echo-Live](https://github.com/sheep-realms/Echo-Live) と [羊のアニメーションスタンプ拡張](https://github.com/sheep-realms/Echo-Live-Sheep-realms-EmoteLab-Extension) によるもので、作者と画像のライセンスは一覧に表示され、ダウンロードフォルダには出典、定義、ライセンスが保持されます。

**設定 › 素材 › Telegram スタンプ** では Telegram アカウントにログインし、公式の検索でスタンプパックを探すか、パック名や `https://t.me/addstickers/パック名` を入力してパック全体をダウンロードできます。初回ログインには [my.telegram.org](https://my.telegram.org) で取得した自分の API ID と API Hash、国番号付きの電話番号、届いた確認コード、必要なら 2 段階認証のパスワードが必要です。もう一度 **接続 / ログイン** をクリックすると、ローカルのセッションが復元され、認証情報を入れ直す必要はありません。

ダウンロード用プロキシは `socks5://127.0.0.1:7890` と認証付きの `socks5://ユーザー名:パスワード@ホスト:ポート` に対応し、空欄なら直接接続します。変更後は再接続してください。ログイン、検索、ファイルのダウンロード、データセンター間の接続はすべて同じプロキシを使います。この設定は Telegram 専用です。

静止画 WebP、TGS ベクターアニメーション、透過付き VP9 WebM に対応します。ダウンロード後はローカルフォルダと同じ解析・事前変換・登録の流れをたどり、同じスタンプ一覧と下部のシリーズタブに `tg_パック名/ファイルID` として表示されます。アニメーションは PNG の全フレームキャッシュに変換され、再起動後もオフラインで再利用できます。Telegram のサイズや長さの制限、または現在のレンダラーの対応範囲を超えるアニメーションは明示的にエラーになります。元ファイルと出典は保持され、スタンプの権利はそれぞれの作者に帰属します。

API Hash、電話番号、確認コード、パスワードはログイン中にのみ使われ、設定には書き込まれません。認可済みセッションはアプリのデータフォルダ内の `telegram.session` に別途保存され、Windows では現在のユーザーの DPAPI で暗号化され、他のプラットフォームでは現在のユーザーのみが読み書きできる権限になります。このセッションファイルは共有しないでください。**ログアウトしてセッションを削除** でログアウトしてローカルのセッションを削除します。ダウンロード済みのスタンプは引き続きオフラインで使えます。

## スキン

スキンは `skin.toml` を含むフォルダか `.ntpkg` アーカイブで、内蔵スキンを継承して差分だけを書くことができます。形式は [スキンの形式](skins.md) を参照してください。

サウンドパックは `sounds.toml` を含むパッケージです。**設定 › 再生 › サウンドパック** で選ぶと、スキンのタイプ音、開始音、続行音を置き換えます。その他の効果音は引き続きスキンが提供します。[サウンドパック](skins.md#サウンドパック) を参照してください。
