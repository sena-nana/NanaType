# 使い方ガイド

NanaType を初めて使う方のために、入力・配信・接続・出力・履歴・アクセシビリティを操作順に説明します。目的から探すときは下の案内を使い、仕様の詳細は各リファレンスへ進んでください。

**このページの案内**：基本操作 → チャットとオンライン接続 → OBS → 音声と翻訳 → 履歴と設定 → アクセシビリティ → マークアップ → スタンプとスキン

日々の操作、配信プラットフォームと OBS への接続、オンライン接続、スタンプ、スキンについての説明です。機能の概要は [README](../../README.ja.md) をご覧ください。

## 基本操作

1. 起動すると入力ウィンドウが画面下部に表示され、以後は動かした位置とサイズを記憶します。入力ウィンドウを閉じるとトレイに隠れ、下書きは残ります。F8 で再び呼び出せます。表示ウィンドウと履歴ウィンドウは透明なオーバーレイです。
2. 入力ウィンドウにそのままセリフを打ち、**Enter** で送信します（Shift+Enter で改行。設定で Ctrl+Enter 送信に変更できます）。Ctrl+↑ / ↓ で送信済みのセリフを呼び戻し、Esc で隠します。
3. 文字を選択してツールバー（または Ctrl+B / I / U）で太字、色、縁取り、ルビ、エフェクト、リズムを付けます。何も選択していないときは、その後に打つ文字に適用されます。ポーズ、改ページ、効果音、表情などのマーカーは文字の間に細い縦線で表示され、レイアウト幅を取らないため、入力ウィンドウと表示ウィンドウの折り返しは完全に一致します。
4. ツールバーの `</>` ボタンでマークアップのソース表示に切り替わります。どちらも同じセリフを編集しています。
5. グローバルホットキー：**F8** で入力ウィンドウを呼び出し、**F9** で続行（ポーズを越える／現在の段落をスキップ）。
6. トレイメニューから各ウィンドウの表示／非表示、オーバーレイのロック、モードとスキンの切り替え、設定を開くことができます。トレイアイコン自体も状態を表します。ミラー中はピンクの丸、表示ウィンドウと履歴が両方隠れているとグレー、オーバーレイがロック中は小さな鍵が付きます。

表示ウィンドウ、接続相手の表示枠、履歴ウィンドウは左ドラッグで移動、ホイールで縦横比を保って拡大縮小できます。右クリックメニューからウィンドウを閉じる、全体のスキンを切り替える／スキン調整を開く、**最前面に表示** の切り替え、**ウィンドウをロック**、**位置とサイズを初期状態に戻す** が使えます。自分の表示ウィンドウでは続行、再生中のスキップ、表示のクリアもでき、履歴ウィンドウではアバター・名前・時刻の表示切り替えと、**履歴を消去 › クリアを確定** による今回の履歴の消去ができます（オンライン接続中は使えません）。ロックするとマウス操作が透過します。解除はトレイか **設定 › ウィンドウ** から行います。ウィンドウを閉じても隠れるだけで、有効な Spout2／Syphon 出力は動き続けます。ネイティブの右クリックメニューが共有テクスチャ出力に映り込むことはありません。

入力モード：

どちらの編集モードもホイール／トラックパッドのスクロールと PageUp／PageDown による移動に対応し、Shift で選択範囲を広げられます。右クリックメニューには元に戻す、やり直し、切り取り、コピー、貼り付け、すべて選択があります。IME で変換中は、Enter、Esc、矢印キーが IME に優先して渡されます。

- **編集して送信**：書き終えてから送信し、表示ウィンドウがタイプライターのリズムで再生します。
- **ミラー（リアルタイム）**：表示ウィンドウが入力をリアルタイムに追いかけ、送信するとセリフが履歴に入ります。

### Twitch チャットとセリフの送信

1. **設定 › Twitch** を開き、チャンネル名か `https://www.twitch.tv/チャンネル名` を入力して **チャットを受信** をオンにします。チャットの読み取りにログインは不要です。
2. セリフを送信するには **Twitch でログイン** をクリックし、twitch.tv/activate を開いてページに表示されたコードを入力します。トークンは OS の保護ストレージ（Windows DPAPI／macOS キーチェーン）に保存されます。
3. **セリフを Twitch チャットに送信** をオンにして確認すると、以後送信したセリフがあなたとしてチャンネルに投稿されます。長いセリフは 500 文字ごとに分割され、失敗したときはキューが一時停止し、再試行かスキップを待ちます。

プロトコル、ログイン、レート制限の詳細は [Twitch 連携](twitch.md) を参照してください。

### blivechat と彗星号

**設定 › ライブ配信 › blivechat** を開き、オンにしてソースを選びます。

- **blivechat**：blivechat を起動し（既定は `127.0.0.1:12450`）、bilibili オープンプラットフォームの認証コードを入力して **保存して接続** をクリックするか、ルーム番号を使います。認証コードは OS の保護ストレージ（Windows DPAPI／macOS キーチェーン）に保存され、設定ファイルには書き込まれません。
- **彗星号**：先に彗星号クライアントを起動して配信ルームの監視を始めます。NanaType がクライアントに直接接続して（既定のポートは 19400）コメントを読み取るので、プラグインは不要です。仕組みは [彗星号連携](comet.md) を参照してください。

LAPLACE Event Bridge は隣の別ページ（**設定 › ライブ配信 › LAPLACE**）で個別にオンにでき、両方を同時に接続できます。手順は [LAPLACE 連携](laplace.md) を参照してください。

これらのコメントはコメントパネルに表示され、@、返信、履歴への混在も同じように使えます。配信ルームがない場合は、モックサーバーで blivechat モードを試せます。

```bash
cargo run -p nanatype-blive --example mock_blivechat
```

彗星号モードでも、彗星号クライアントの代わりにモックサーバーを使えます。

```bash
cargo run -p nanatype-blive --example mock_comet
```

### オンライン接続

1. Steam が起動している必要があります。入力ウィンドウ下部のバーから接続の入口を開き、ホストが **接続を作成** をクリックします。ルームは最大 8 人で、パスワードも設定できます。パスワードは招待には含まれません。
2. **フレンドを招待** で Steam の招待が開きます。招待されたフレンドはパスワード入力が不要です。コピーした招待を他の人に渡した場合、ルームがロックされていれば参加前にパスワード入力が必要です。
3. **表示ウィンドウ** には常に自分の内容が表示されます。他の各メンバーには席ごとに専用の **接続相手の表示枠** ウィンドウが開きます（席 1 がホスト、以降は参加順）。まだ誰も入っていないときは席 1 のウィンドウに招待と承諾状況が表示されます。これらのウィンドウは表示・ロック・サイズの設定を共有し、位置は席ごとに記憶されます。共有履歴には、ホストが確定した順序で全員の送信内容が入ります。スキンとウィンドウ配置は各自のものが保たれます。ミラーでは入力中の内容が公開され、編集して送信では送信済みの内容だけが公開されます。F9、スキップ、表示のクリアは自分にだけ作用します。
4. 接続中、履歴ウィンドウには今回のセッションのセリフが表示されます。接続前の履歴や配信ルームのコメントは共有されません。退出するとローカルの履歴に戻ります。セッションはプロセスを再起動すると復元されません。セッションは直近 1000 件までのセリフを保持し、メッセージサイズの上限に応じてさらに切り詰められます。
5. 切断中も編集はできますが、送信と手動の再生操作は一時停止します。切断すると席は空きますが、空席があれば同じ人が再接続でき、送信済みのセリフは残ります。ホストが退出するとルームは終了します。

画像、スタンプ、アバター、引用内のアバター、現在の立ち絵はコンテンツハッシュで配布されます。プレビューはホストが中継し、完全な画像は投稿者から直接取得し、直接接続に失敗したときはホストに求めます。1 リソースの上限は 16 MiB で、超過や欠落時はプレースホルダーを表示します。ローカルの VTube Studio／OSC などのキャラクター操作をトリガーするのは自分のセリフだけです。

Steam が直接接続できれば直接、できなければ Steam のリレーを経由します。直接接続の場合、相手からネットワークアドレスが見えます。

### OBS への接続

- **Spout2**：**設定 › 出力 / OBS** で Spout2 出力をオンにします。OBS に Spout2 プラグインを入れて *Spout2 Capture* を追加し、送信元名（既定は `NanaType Display` / `NanaType Partner 1`… / `NanaType History`）を選び、合成モードを *Premultiplied Alpha* にします。
- **個別出力**：自分の **表示ウィンドウ** は **設定 › 出力 / OBS** で有効にし、OBS で `NanaType Display` を選びます。接続相手は一人ずつ出力があり、入力ウィンドウの接続パネルの **配信出力** で席ごとにオンにし、OBS で `NanaType Partner 1`〜`NanaType Partner 7` を選びます。出力は席で記憶され、その席に座った人がその出力に送られ、空席では何も送りません。有効な送信元名は互いに重複できません。共有履歴は `NanaType History` を選びます。
- **ウィンドウキャプチャ**：*Window Capture* で、キャプチャ方法に *Windows 10 (1903 and up)* を選びます。
- **Syphon**（macOS）：**設定 › 出力 / OBS** で Syphon 出力をオンにします。OBS に *Syphon Client* を追加し、送信元名（既定は `NanaType Display` / `NanaType Partner 1`… / `NanaType History`）を選び、合成モードを *Premultiplied Alpha* にします。*macOS Screen Capture* で表示ウィンドウをキャプチャすることもできます。Spout2 は Windows 専用です。

出力をオフにして 5 秒以内にオンに戻すと元の送信元が再利用され、OBS の映像は中央値で約 15〜30 ms で戻ります。送信元のライフサイクルと実際の OBS での計測は [OBS / Spout 出力](obs-spout.md) を参照してください。

### キャラクター情報

- **設定 › キャラクター情報** で、セリフを話すキャラクターを管理します。各キャラクターには名前、アイコン、名札の名前の色（**スキンの色に戻す** でスキンの色に戻ります）があり、追加・並べ替え・削除ができます。最後の 1 人は削除できません。名前を空欄にすると名札を隠します。以前のバージョンのキャラクター名とアイコンは、自動的に 1 人目のキャラクターになります。
- 切り替えは、入力ウィンドウ下部のキャラクターボタン（2 人以上いるときに表示）、トレイの **キャラクター** サブメニュー、または **設定 › ホットキー › キャラクター切り替え** の **次のキャラクター**・**前のキャラクター** と各キャラクターのホットキーで行います。現在のキャラクターは記憶されます。セリフは送信時に話者を記録するため、あとで切り替えたり名前を変えたりしても、履歴、保存した記録、接続相手に見えるセリフ、`line_start` イベントの `speaker` は変わりません。
- **設定 › ホットキー** では **オーバーレイのロック/解除**、**直前のセリフを再生**（表示ウィンドウでもう一度再生するだけで、配信のチャットには送らず履歴も増えません。協力プレイ中はパートナーのウィンドウでも再生され、パートナーのセリフを読み上げる設定ならもう一度読まれます。ルームに入る前のセリフは除きます）、**履歴の表示/非表示** も割り当てられます。初期状態ではいずれも未割り当てです。トレイのロックと **直前のセリフを再生** の項目も同じ動作です。

### 読み上げ

- 「設定 › 音声 › 読み上げ › 送信したセリフを読み上げる」（既定はオフ）をオンにすると、セリフが表示され始めるたびに OS 標準の音声で読み上げます。macOS は AVSpeechSynthesizer を使います。Windows では OneCore の音声（WinRT。NanaType 自身の音声出力から再生されるため「サウンド」で選んだ出力デバイスで鳴り、語のタイミングも得られます）と SAPI の音声を一緒に並べ、同じ名前は一つだけ（OneCore のほう）表示します。ダウンロードもネット接続もありません。音声はシステム設定で追加し、追加後に「音声を更新」を押してください。
- 読むのはセリフの文字です。ルビは親文字、メンションは視聴者の名前として読み、スタンプ・画像・マーカーは読みません。スタンプや記号だけのセリフは読み上げません。
- 新しいセリフは読み上げ中のセリフを打ち切ります。「セリフをスキップ」と「表示ウィンドウを消去」で止まり、「直前のセリフを再生」でもう一度読みます。
- 「既定の音声」と、キャラクターごとの音声を選べます（一覧は最初は表示言語の音声だけ。「音声の言語」で他の言語やすべてを表示）。「速さ」「音量」はすべての音声に共通で、「試聴」でサンプルを再生します。
- 「視聴者のコメントも読み上げる」「コラボ相手のセリフも読み上げる」は既定でオフです。既定の音声で、読み上げ中の内容の後に読みます。コメントは履歴に入るものだけ、相手のセリフは表示されたときに一度だけ読みます。
- 「読み上げに合わせて表示」（既定はオフ）をオンにすると、タイプライターは音声が読んだ語までを語ごとに表示します。音声が 0.3 秒以内に語のタイミングを返さないとき（または読み上げが失敗・終了したとき）は、残りをいつもの速さで表示します。続行やスキップではいつもどおりすぐに表示されます。
- 読み上げがオンの間、VTube Studio のリップシンク（と `speaking` イベント）はタイプライターではなく音声に合わせて動きます。音声が語のタイミングを返す場合は語の音節ごとに口が開き、語と語の間で閉じます。返さない場合は一定のリズムで動きます。
- スイッチ、既定の音声、速さ、音量と各オプションは共通の設定です。キャラクターごとの音声はキャラクターと一緒にプロファイルに入ります。

### 翻訳字幕

- **設定 › 翻訳字幕 › 送信したセリフを翻訳**（既定はオフ）は、各セリフを **翻訳先** の言語（既定は英語。一覧にない言語は **その他の言語コード** に `pt-BR` などを入力）に翻訳します。元の言語は自動で判別します。翻訳が届くと、今のページの最後の行のすぐ下に小さく控えめな字幕としてフェードインし（ウィンドウは常に字幕 1 行分の場所を空けておくので、ページ送りで枠の外に押し出されることはありません）、スキンのフォント・縁取り・影を引き継ぎます。入力と送信が翻訳を待つことはなく、すでに次のセリフに替わった後で届いた翻訳はウィンドウには出ません（履歴には入ります）。**動きを減らす** がオンのときはフェードせずに表示します。縦書きでは最後の行の後（左側）に 1 列の字幕として表示します。
- **サービス**：**OpenAI 互換** は OpenAI、DeepSeek（`https://api.deepseek.com/v1`）、このコンピューター上の Ollama（`http://localhost:11434/v1`）や LM Studio（`http://localhost:1234/v1`）に対応します。**エンドポイント**（`/v1` まで）と **モデル** を入力します。ローカルのサーバーにはキーは不要です。プロンプトは翻訳だけを短く、名前はそのまま返すよう求め、話者を文脈として渡します。**DeepL** はキーだけで使え、`:fx` で終わるキーは無料版 API を使います。
- **API キー** はシステムの資格情報ストア（Windows 資格情報マネージャー／macOS キーチェーン）に保存し、設定ファイルやエクスポートには含めません。**プロキシ** が空欄ならシステムのプロキシを使い、このコンピューター上のサーバーには常に直接接続します。
- **翻訳するセリフ**：**自分のセリフ** は既定でオン。**接続相手のセリフ** は相手が翻訳を付けずに送ったものだけを翻訳します（相手が翻訳をオンにしていれば、その翻訳がセリフと一緒に届きます）。**視聴者のチャット** は履歴に入るコメントを翻訳します。
- **表示場所**：**ダイアログに表示** と **履歴に表示** は別々に切り替えられます。保存した履歴には常に翻訳が残り、`.txt` のエクスポートでは本文の次の行に、`.srt` では字幕の 2 行目になります。WebSocket／プラグインのイベント：翻訳がすでにわかっている場合（再生し直しや同じセリフ）は `line_start` に `translation` が付き、そうでなければ届いた時点で `translation` イベント（`id`、`text`、`target`）が送られます。OSC は `/translation` を送ります。
- 直近 256 件の翻訳はメモリに保持され、再生し直しや同じセリフはすぐに表示されます。リクエストは 8 秒でタイムアウトし、待機中の古いリクエストは新しいセリフに置き換えられます。失敗しても送信は止まりません。設定ページのステータス表示に理由が出て、同じ種類の失敗は一度だけ通知します（**テスト** で現在の設定のままサンプルを翻訳できます）。
- 翻訳の設定は共通で、プロファイルでは切り替わりません。

### 履歴の保存と検索

- **自動保存**：送信したセリフ（オンライン接続中は相手のセリフも）は、初期設定でデータフォルダの `history/` に配信ごとに 1 つの JSON Lines ファイル（例：`2026-11-02_213005.jsonl`）として 1 行ずつ追記されます。クラッシュしても失うのは書き込み中の 1 行までです。視聴者のコメントは **設定 › 履歴 › 履歴の保存 › 視聴者のコメントも保存** をオンにしたときだけ（初期設定はオフ）、履歴に入ったものだけ保存されます。**保存期間（日）** は初期設定で 30 日で、起動時にそれより古い記録を削除します。0 で無期限です。**履歴を消去** はウィンドウの履歴だけを消し、保存ファイルは削除しません。
- **表示と書き出し**：**設定 › 履歴 › 保存した記録** に各回の開始時刻と行数が並びます。**表示** でその回のセリフ（時刻 · 名前 · 内容。まず最新の 500 行を表示し、上部の **さらに前の … 行を表示** で前の分を順に読み込んで、最初まで遡れます）を確認し、`.txt` で、または `.srt` 字幕で書き出せます。字幕はその回の最初のセリフを 0 秒とし、各行を次の行が始まるまで、または文字数から見積もった読み時間だけ表示します。**削除** は確認のうえその回のファイルを削除し、**フォルダを開く** で保存場所を開きます。
- **検索**：履歴ウィンドウがロックされていないとき、右上の検索ボタンが入力欄に開き、内容または名前で絞り込みます（大文字小文字を区別しません）。もう一度ボタンを押すか Esc で閉じて絞り込みを解除します。履歴ウィンドウの Spout2／Syphon 出力がオンの間は検索できず、出力には常にすべての履歴が映ります。

### プロファイル、エクスポートとインポート

- **プロファイル**：**設定 › プロファイルとバックアップ › プロファイル** で現在の設定に名前を付けて保存できます（「歌枠」「雑談」など）。切り替え、名前の変更、複製、現在の設定での上書き、削除ができます。トレイの「プロファイル」サブメニューや、**設定 › ショートカット** の「次のプロファイル」（一覧の順に切り替え、既定は未割り当て）や、**設定 › ショートカット › プロファイル** で各プロファイルに割り当てたキーでも切り替えられます。プロファイルのキーはほかのグローバルホットキーと同じくプロファイルでは変わりません。切り替え先のプロファイルの定型文やキャラクターのホットキーがグローバルホットキー（または互い）と重なる場合はグローバルのほうが優先され、重なったものは変更するまで登録されず、その名前を通知します（定型文がキャラクターより先、それぞれ一覧の順）。切り替える前に、使用中のプロファイルでの変更をそのプロファイルに保存します。プロファイルは設定フォルダーの `profiles/<id>.json` に `settings.json` と同じくアトミックに書き込まれます。
- **プロファイルに入るもの**：キャラクター（アバター、色、ショートカットを含む）と使用中のキャラクター、再生、サウンド（出力デバイスを除く）、スキンと調整（設定ウィンドウのライト／ダーク表示とホットリロードを除く）、オーバーレイウィンドウの表示・ロック・最前面・サイズ、履歴ウィンドウ（履歴の保存設定を除く）、クイックフレーズ。それ以外はすべて共通です：言語、ショートカット、入力方式、連携とそのアドレスやチャンネル、出力、音声入力、読み上げ（キャラクターごとの音声はキャラクターと一緒）、アップデート、自動起動、プラグイン、画面上のウィンドウ位置。
- **エクスポート**：**設定 › プロファイルとバックアップ › バックアップと移行 › 設定をエクスポート** で、アプリ名、設定のスキーマ、エクスポート日時、NanaType のバージョンを含む `.json` ファイルを保存します。連携のアドレスとチャンネル（既定で含む）、キャラクターのアバター（既定で含む。画像はファイルに埋め込まれ、4 MB を超えるものや見つからないものは含まれず、後で件数を表示）、ウィンドウの位置（既定で含まない。モニター構成ごとの記録なので別の PC にはまず合いません）を選べます。ログイン情報とパスワード（Twitch、OBS、blivechat の身分コード）はシステムのキーチェーンにあり、エクスポートされません。VTube Studio のプラグイントークン、プロキシの `ユーザー:パスワード@` も含まれません。プラグインの承認、オーディオデバイス、GPU とログの設定、使用中のプロファイルはこの PC のものなので、これも含まれません。
- **インポート**：**設定をインポート** は、エクスポートしたファイルか手でコピーした `settings.json` を読み込みます。古いバージョンのファイルは設定の移行で先に更新し、新しいバージョンの NanaType のファイルは拒否します。確認ダイアログに変更される項目が表示され、確認するまで適用されません。現在の設定は先に `settings.previous.json` に自動でバックアップされ、「以前の設定に戻す」で元に戻せます（もう一度押すとインポート後の設定に戻ります）。連携を含まないファイルでは現在の連携を残し、この PC のログイン情報は常に残ります。埋め込まれたアバターはデータフォルダーの `avatars/` に書き出されます。
- **すべて初期設定に戻す**：確認後、設定を新規インストール時の状態に戻します。言語、初回ガイドの完了状態、ログイン情報は残ります（キーチェーンのパスワードはそのままで、ログアウトしません）。こちらも先に自動でバックアップされ、「以前の設定に戻す」で元に戻せます。ウィンドウの位置とプロファイルは変わりません。

### アクセシビリティ

- **設定 › 一般 › アクセシビリティ** が変えるのはアプリ自身のウィンドウだけです：設定、入力ウィンドウ（履歴・コメントパネルを含む）、パッケージエディター。スキンと、会話・パートナー・履歴ウィンドウの画面（Spout2／Syphon 出力を含む）は常にそのままです。
- **ハイコントラスト**：**システムに従う**・**オフ**・**オン**。オンにすると、不透明な白黒の配色になり、本文は 7:1 以上、枠線・コントロールの輪郭・フォーカス表示は 3:1 以上のコントラストになり、線とフォーカス枠も太くなります。**システムに従う** は Windows のハイコントラストテーマと macOS の **コントラストを上げる** に従い、切り替えるとすぐに反映されます。
- **画面の大きさ**：80%〜200%（既定は 100%）。システムの表示スケールに加えて、文字・コントロール・アイコン・余白、スキンのプレビューまでウィンドウの中身全体をまとめて拡大します。ウィンドウの最小サイズはすぐに変わり、小さすぎる開いているウィンドウは自動で広がります。パッケージエディターは次に開いたときに反映されます。
- **システムの文字サイズに合わせる**（Windows のみ）：**設定 › アクセシビリティ › テキストのサイズ** を画面の大きさとして使い、変更にすぐ追従します。
- **動きを減らす** は **設定 › 再生** にあります。システムの「視差効果を減らす」設定でもオンになります。
- すべてのコントロールにスクリーンリーダーが読み上げる名前があり、スイッチとスライダーは現在の状態を伝えます。Tab／Shift+Tab で移動し、Enter かスペースで操作し、Esc でダイアログとポップアップメニューを閉じます。履歴の消去など二度確認する操作では、確認ボタンにフォーカスが移ります：Enter で実行、Esc で取り消して元のボタンに戻ります。
- これらの設定はグローバルで、プロファイルでは切り替わりません。

### アップデートの確認

Steam 版は Steam が更新するため、この項目はありません。GitHub 版は **設定 › 情報** で GitHub Release の新しいバージョンを確認でき、**設定 › 一般 › アップデート** では既定で 1 日 1 回自動確認します。新しいインストーラーは検証に通ってから開かれます。ダウンロードは GitHub と内蔵プロキシ（gh-proxy.com、ghfast.top、ghproxy.net）を同時に試し、カスタムプロキシを 1 つ追加することもできます。プロキシは転送のみを担い、バージョンマニフェストには Ed25519 署名があり、インストーラーは SHA-256 で検証されます。詳しくは [アップデートの確認](updates.md) を参照してください。

## セリフのマークアップ

セリフは BBCode 風のマークアップで保存され、ソースモード、定型文、テンプレートで共通です。詳しくは [セリフのマークアップ](markup.md) を参照してください。

## スタンプ

**設定 › 素材 › スタンプ** では、「羊のピクセルアバター（静止画）」と「羊のアニメーションスタンプ」のプリセットをダウンロードできるほか、ローカルの画像フォルダ、Echo-Live のルートフォルダ（`res/data/emoji.js` を含む）、Echo-Live のスタンプ拡張フォルダ（`main.js` を含む）を追加できます。プリセットはクリックしたときだけネットからダウンロードし、その後はローカルフォルダと同じ取り込み・管理の流れになります。

取り込み時には、画像、サムネイル、GIF の全フレームキャッシュをバックグラウンドで準備し、一覧にダウンロード中・処理中・使用可能・失敗の状態を表示します。完了後はオフラインで使え、元ファイルは変更されず、変化のない内容は再起動後もキャッシュを再利用します。画像や表情定義を変更すると該当キャッシュが自動で再構築されます。削除は読み込みをやめるだけで、元ファイルは消しません。

入力ウィンドウのスタンプパネルで名前やパック名を検索してクリックすると挿入され、`[sticker=sp/happy h=1.35]` や `[sticker=sprel/laugh h=4]` のような NanaType のマークアップとして保存されます。アニメーションスタンプはプレビュー、表示、履歴、Spout／Syphon 出力で再生され、動きを減らす設定では最初のフレームを表示します。この機能は Echo-Live の画像スタンプ定義を読むだけで、拡張スクリプトは実行しません。

入力ウィンドウ右側のスタンプ欄には、下部に「すべて」とシリーズ別のサブタブがあり、スタンプのグリッドは単独でスクロールし、検索は現在のシリーズだけを絞り込みます。1 つ以上のフォルダをスタンプ欄か上部のスタンプタブにドラッグすると素早く追加できます。タブにドロップすると欄が自動で開き、取り込んだものは設定ページと一緒に管理されます。

プリセット画像は [Echo-Live](https://github.com/sheep-realms/Echo-Live) と [羊のアニメーションスタンプ拡張](https://github.com/sheep-realms/Echo-Live-Sheep-realms-EmoteLab-Extension) によるもので、作者と画像のライセンスは一覧に表示され、ダウンロードフォルダには出典、定義、ライセンスが保持されます。

**設定 › 素材 › Telegram スタンプ** では Telegram アカウントにログインし、公式の検索でスタンプパックを探すか、パック名や `https://t.me/addstickers/パック名` を入力してパック全体をダウンロードできます。初回ログインには [my.telegram.org](https://my.telegram.org) で取得した自分の API ID と API Hash、国番号付きの電話番号、届いた確認コード、必要なら 2 段階認証のパスワードが必要です。もう一度 **接続 / ログイン** をクリックすると、ローカルのセッションが復元され、認証情報を入れ直す必要はありません。

ダウンロード用プロキシは `socks5://127.0.0.1:7890` と認証付きの `socks5://ユーザー名:パスワード@ホスト:ポート` に対応し、空欄なら直接接続します。変更後は再接続してください。ログイン、検索、ファイルのダウンロード、データセンター間の接続はすべて同じプロキシを使います。この設定は Telegram 専用です。

静止画 WebP、TGS ベクターアニメーション、透過付き VP9 WebM に対応します。ダウンロード後はローカルフォルダと同じ解析・事前変換・登録の流れをたどり、同じスタンプ一覧と下部のシリーズタブに `tg_パック名/ファイルID` として表示されます。アニメーションは PNG の全フレームキャッシュに変換され、再起動後もオフラインで再利用できます。Telegram のサイズや長さの制限、または現在のレンダラーの対応範囲を超えるアニメーションは明示的にエラーになります。元ファイルと出典は保持され、スタンプの権利はそれぞれの作者に帰属します。

API Hash、電話番号、確認コード、パスワードはログイン中にのみ使われ、設定には書き込まれません。認可済みセッションはアプリのデータフォルダ内の `telegram.session` に別途保存され、Windows では現在のユーザーの DPAPI で暗号化され、他のプラットフォームでは現在のユーザーのみが読み書きできる権限になります。このセッションファイルは共有しないでください。**ログアウトしてセッションを削除** でログアウトしてローカルのセッションを削除します。ダウンロード済みのスタンプは引き続きオフラインで使えます。

## スキン

スキンは `skin.toml` を含むフォルダか `.ntpkg` アーカイブで、内蔵スキンを継承して差分だけを書くことができます。形式は [スキンの形式](skins.md) を参照してください。

サウンドパックは `sounds.toml` を含むパッケージです。**設定 › 再生 › サウンドパック** で選ぶと、スキンのタイプ音、開始音、続行音を置き換えます。その他の効果音は引き続きスキンが提供します。[サウンドパック](skins.md#サウンドパック) を参照してください。
