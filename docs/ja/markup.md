# セリフのマークアップ

マークアップは入力ウィンドウの編集エリアに書き、ツールバーとサイドバーが代わりに挿入してくれます。解析は決して失敗しません。認識できないタグはそのまま文字として表示され、ステータスバーに通知されます。`[[` はリテラルの `[` を表します。

## スタイル（ペアで使用）

| マークアップ | 効果 |
| --- | --- |
| `[b]…[/b]` `[i]…[/i]` `[u]…[/u]` `[s]…[/s]` | 太字、斜体、下線、取り消し線。`[b=0]` はスキン既定の太字を解除 |
| `[color=#e86a92]…[/color]` | 文字色。`#rgb` `#rrggbb` `#rrggbbaa` |
| `[size=1.5]…[/size]` `[size=32px]…[/size]` | 文字サイズ：スキンの文字サイズの倍率、またはピクセル |
| `[align=center]…[/align]` | 段落の揃え：`start` / `center` / `end`。空の段落にも使えます。指定がなければスキンに従います |
| `[font=accent]…[/font]` `[font="Noto Serif SC"]…[/font]` | スキンのフォントスロット（body / name / accent）または指定のフォントファミリー |
| `[stroke=#ffffff,2]…[/stroke]` | 縁取り：色、幅 |
| `[shadow=#000000aa,2,2,4]…[/shadow]` | 影：色、x、y、ぼかし |
| `[ruby=かんじ]漢字[/ruby]` | ルビ |

## 文字ごとのエフェクト（ペアで使用）

| マークアップ | 効果 |
| --- | --- |
| `[shake]` `[wave]` `[jump]` `[rainbow]` `[pulse]` `[flicker]` | 震え、波、ジャンプ、虹色、脈動、点滅。`amp=` と `speed=`（スキン既定値の倍率）を付けられます |
| `[fade]` `[pop]` `[slide]` | 登場：フェードイン、ポップ、浮き上がり。`[pop=120]` でミリ秒を指定。1 つのセリフの登場は 1 種類だけで、最も多くの文字を覆うものが選ばれてセリフ全体に適用され、設定やスキンより優先されます |


持続エフェクトは入れ子にして組み合わせられます。例：`[wave][rainbow]波浪彩虹[/rainbow][/wave]`。同じ区間ではすべての効果が保たれます。`amp=0` でその効果をオフにでき、動きを減らすモードではすべての持続エフェクトがオフになります。

## リズム

| マークアップ | 効果 |
| --- | --- |
| `[speed=0.5]…[/speed]` | 部分的な速度変更：倍率（0.5 で 2 倍速） |
| `[speed=40ms]…[/speed]` | 1 文字あたりのミリ秒を固定 |
| `[instant]…[/instant]` | 区間全体を一瞬で表示 |
| `[em]…[/em]` | 強調：太字と字間に加え、各文字の前後に 100 ミリ秒ずつ間を置き、一文字ずつ区切ります。`[em=200]` で片側のミリ秒を指定（スペースでは止まりません） |
| `[wait=500]` | 500 ミリ秒停止 |
| `[pause]` | 止まって続行キーを待つ |
| `[pause auto=2000]` | 止まって 2 秒後に自動で続行 |
| `[page]` | 続行を待ってから表示ウィンドウをクリアし、枠の上端から続きを打つ |

セリフが表示ウィンドウの高さを超えた場合の扱いはスキンの `overflow` で決まります（**設定 › スキン › はみ出したとき** で上書き可能）。`scroll` は枠の下端まで打つと全体を 1 行スクロールし（既定）、`page` は 1 ページ埋まると続行を待ってからページをめくり（`[page]` を自動挿入するのと同じ）、`clip` はそのまま切り捨てます。

## 効果音・表情・画面

| マークアップ | 効果 |
| --- | --- |
| `[se=coin]` `[se=coin vol=0.6]` | スキン内の `coin` という名前の効果音を再生 |
| `[expr=smile]` | 表情をトリガー：同名の立ち絵差分に切り替え、VTube Studio / OSC / WebSocket に送信。VTube Studio では同名の（または設定で割り当てた）ホットキーに対応する表情をオンにします |
| `[portrait=happy]` | 立ち絵差分だけを切り替え |
| `[screenshake=6,300]` | 表示ウィンドウを揺らす：振幅、ミリ秒 |
| `[sticker=cats/hello h=1.6]` | スタンプライブラリ `cats` の `hello` を、文字サイズの 1.6 倍の高さで挿入 |
| `[emote=wave]` | スキン付属のエモート `emotes/wave` を挿入 |
| `[img="file:C:/pic.png" alt="图"]` | 画像を挿入 |
| `[at=1234 name="观众" avatar=blob:bili-face-1234]` | 配信ルームの視聴者にメンション：アバターとニックネーム付きのタグで表示され（スタイルはスキンの `[mention]`）、全体で 1 文字として扱われます。`at` の値は bilibili の uid で省略可、`avatar` も省略可。通常はコメントパネルの「@」ボタンで挿入され、「返信」は元メッセージの引用だけを添付します |

## VTube Studio

以下のマークアップはいずれも、その位置まで打ち進んだときに送信されます。スキップした場合、スキップした部分にあるマークアップはただちに送信されます。

| マークアップ | 効果 |
| --- | --- |
| `[vts hotkey=挥手]` | 現在のモデルのホットキー（名前または ID）を押す |
| `[vts expr=Smile.exp3.json]` | 表情ファイルをオン |
| `[vts expr=Smile.exp3.json active=off fade=0.3]` | 表情ファイルをオフにし、0.3 秒でフェードアウト |
| `[vts param=MouthSmile value=0.8 ms=1500]` | パラメーターを 0.8 にして 1.5 秒保持（`ms` を省略すると一度だけ設定） |

連携設定では、口パク（打鍵中に `MouthOpen` などのパラメーターを動かし、ポーズ中は口を閉じる）や、セリフが表示ウィンドウを離れたとき・次のセリフが始まったときに、そのセリフでオンにした表情をリセットする機能も有効にできます。

## セリフ全体の設定

先頭に書きます。

```text
[@auto=1500 after=fade delay=800 per=20]
```

- `auto`：再生終了後、何ミリ秒で次のセリフへ自動的に進むか（キューモード時）。
- `after`：`hold` で保持、`fade` でフェードアウト（`delay` は残るミリ秒、`per` は 1 文字あたりの追加ミリ秒）、`clear` で即座に消去。

## 定型文のテンプレート

定型文では `{{name}}`（キャラクター名）と `{{time}}`（現在時刻）が使えます。

入力ウィンドウ右側のサイドバーは、アイコンバーで **コントロール**、**スタンプ**、**定型文**、**コメント** の 4 つのパネルを切り替えます。現在のアイコンをもう一度クリックするとサイドバーが閉じます。**コントロール** パネルでは、上記のリズム、画面とサウンド、表情のマークアップがエディタと同じチップになっていて、クリックするとカーソル位置に挿入されます。文字エフェクト、登場、速度は括弧付きで、選択範囲に作用します。タイルにカーソルを合わせると説明とマークアップのソースが表示され、上部で検索もできます。コメントはピンでサイドバーの上半分に固定でき、下のパネルとの境界線はドラッグで動かせます。

ツールバーが扱うのは文字の見た目だけです：太字、斜体、下線、取り消し線、色、文字サイズ、フォント、揃え、縁取り、ルビ、書式のクリア。ツールバーには段落の揃え、文字サイズ、フォントのパネルがあります。揃えはカーソルのある段落か選択した段落に作用します。文字サイズはスキンの文字サイズの倍率（0.5〜3×）か固定ピクセル（4〜400px）を選べます。フォントはスキンの本文・名前・強調のフォントスロットを使うか、フォントファミリー名を入力します。パネルには現在の属性が表示され、選択範囲内で一致しないときは **混在** と表示されます。

**スキンに従う** は対応する上書きを解除します。ソースでは `[size=inherit]…[/size]`、`[font=inherit]…[/font]` で外側のスタイルの中で継承に戻せます。倍率とフォントスロットはスキンに合わせて変わり、ピクセル指定の文字サイズと指定したフォントファミリーは固定のままです。書式のクリアは、対象の段落の揃えも既定に戻します。
