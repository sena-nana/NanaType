# 彗星号連携

彗星号の配信コメントを NanaType に取り込むための設定・接続仕様です。まず [使い方ガイド](usage.md) で基本設定を確認し、接続できないときはデータの流れと移行手順を確認してください。

**このページの案内**：データの流れ → 使い方 → フィールド対応 → テスト → 旧方式からの移行

[彗星号](https://huixinghao.cn/) は配信支援ツールです。彗星号クライアントはこの PC 上で自らコメント用の WebSocket を提供しており、NanaType はそこへ直接接続して、クライアントが監視しているすべての配信ルームを読み取ります。プラグインページも中継も必要ありません。

## データの流れ

```
彗星号クライアント（配信ルームを監視中）
       │  ws://127.0.0.1:19400/      ルートパスで全ルームのメッセージを受信
       │  バイナリフレームは AES-256-GCM で暗号化、テキストフレームは JSON、ping → pong
       ▼
NanaType の接続スレッド（crates/blive/src/client.rs、Join::Comet）
       comet::decrypt() で復号し、comet::parse() でコメントイベントに変換
       ▼
コメントパネル、履歴
```

- バイナリフレームは先頭 12 バイトが nonce、続いて暗号文と末尾 16 バイトの認証タグで、鍵は彗星号が公開している固定鍵です。復号できないフレームは読み飛ばし、以降のメッセージには影響しません。
- 各メッセージは `{ type, platform, rid, data }` の形です。NanaType は接続直後に `ping` を 1 回送り、以後 10 秒ごとに送ります。30 秒間フレームが届かなければ切断とみなし、3 秒後に再接続します。
- 接続先は `127.0.0.1` のみで、ポートは既定で 19400、設定ページで変更できます。

## 使い方

1. 彗星号クライアントを起動し、配信ルームの監視を始めます。
2. NanaType：**設定 › ライブ配信 › blivechat** で受信をオンにし、ソースに **彗星号** を選びます。ポートは彗星号の設定と同じにします（既定は 19400）。
3. 状態が「彗星号 · 接続済み」になると、彗星号が受け取ったコメントがコメントパネルに表示されます。「彗星号に接続できません」と出る場合は、クライアントが起動していないか、ポートが違います。

## フィールドの対応

| 彗星号の `type` | NanaType のイベント | 説明 |
| --- | --- | --- |
| `Chat` | コメント | `content` が本文。`dm_type = 1` はスタンプコメントで、画像は `emoji_img_url` |
| `Gift` | ギフト | `item` がギフト名。`price` は単価（元）として扱い、`合計 = price × num`。価格 0 は無料ギフト |
| `Subscribe` / `Guard` | 大航海 / メンバーシップ | bilibili の大航海と抖音のメンバーシップは `Subscribe`、星守护は `Guard`。`item` に 総督 / 提督 / 舰长 が含まれればその艦隊レベルになり、`vip_unit` は期間 |
| `SuperChat` | スーパーチャット | `price` は元 |
| `EnterRoom`、`Like`、`EndLive`、`ListenerStatus`、`WsClose` | — | コメントではないので無視 |

ユーザー情報は `id`、`name`、`avatar`、ファンメダルは `fans_medal_name`、`fans_medal_level` から読みます。メッセージ ID は `msgId` で、ない場合は内容から組み立てます。bilibili 以外のプラットフォームのユーザーは uid の前にプラットフォーム名を付け（`dou_yin:…` など）、bilibili の uid と衝突しないようにしています。

## テスト

```bash
cargo test -p nanatype-blive
```

彗星号クライアントがない場合は、モックサーバーで代用できます。19400 番ポートで暗号化したサンプルメッセージを繰り返し送ります。

```bash
cargo run -p nanatype-blive --example mock_comet
```

## 仕様上の注意と制限

- `Gift` の `price` は単価（元）として扱い、合計を `price × num` で計算します。価格 0 は無料ギフトです。
- 艦隊レベルは現在 `item` の文字列から判定します。彗星号が `data` に別のレベルフィールドを提供する場合は、その値を使う実装に更新できます。

## 旧バージョンからの移行

以前のバージョンでは、クリエイティブワークショップのプラグインページがイベントを NanaType の中継（ポート 12451、トークン付きの接続アドレス）に送っていました。この方式は廃止されました。設定に保存された旧ポート 12451 は自動で 19400 に変わり、旧トークンは使われなくなります。キャンバス上の旧プラグインは削除してかまいません。
