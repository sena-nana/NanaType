# UI 规则

这些规则面向贡献者和皮肤/插件作者。目标是让文本优先、状态可理解、动效可关闭；皮肤只表达主题，不改变宿主交互语义。

## 交互与布局

- 所有可操作控件必须有清晰的焦点、悬停、按下、禁用和错误状态；键盘操作不能依赖鼠标。
- 文本、输入和继续提示保留稳定位置；装饰、震屏、扫光和粒子不得推动布局或遮挡正文。
- 需要滚动时保留可见滚动位置和继续操作；长文本应自然换行，不用横向滚动代替布局。
- 颜色不是唯一状态信号；同时使用文字、图标、形状或位置。高对比和减少动态设置必须有效。
- 对话历史、引用、说话人、暂停和等待状态在主题之间语义一致。

## 主题与资源

皮肤使用声明的图片、九宫格、WGSL 和数据，不得任意加载网络、文件或执行脚本。复杂画面走 retained Painter；普通背景、图片、圆角和边框走框架样式。切换表面时清除旧图片、边框、阴影和变换字段，避免状态泄漏。

静态回退必须与动态画面保持同一布局；编译失败、GPU 不可用、编辑器预览和减少动态都能显示回退图。动画使用有限时钟和按需刷新，不能在静止界面持续请求帧。资源必须注明来源与许可，内置字体遵守 OFL/RFN 规则。

## 标记与插件

Markup 解析失败时显示安全文本，不执行未知标签；`speaker`、`overflow`、`inherit` 等属性仅作用于声明范围。插件只收到声明的事件和数据，不能读任意路径、访问网络、调用 shell、改变系统设置或绕过用户同意。包完整性校验失败、能力声明不一致或预算超限时拒绝加载。

## 验证清单

```powershell
cargo test --workspace --all-targets --locked
cargo run -p nanatype --example snapshots -- target/ui-rules-snapshots zh-CN
```

至少检查键盘导航、中文长文本、缩放/高 DPI、深浅背景、错误和空状态、减少动态、GPU 后备、无网络启动及离屏输出。报告视觉问题附主题、DPI、窗口尺寸、系统/GPU、复现步骤和脱敏截图；不要附令牌、Cookie 或私人聊天内容。
