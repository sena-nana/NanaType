# 界面规则

设置窗口与各平台卡片的版式规则，取自 NanaLive 的[界面规则](../../NanaLive/docs/design/rules.md)，只保留适用于 NanaType 的部分。构件在 `crates/frame/src/ui/kit/layout.rs` 与 `app/src/ui/settings/controls.rs`。

## 行

- 设置项一行：名称在左，控件在行尾。
- 说明这个设置做什么的文字（`-hint`）不放在名称下面，也不放成行下的提示块，而是控件前的 ⓘ 悬浮说明：`row(ui, key, Some(hint), control)` 自动这样画。
- 名称下面的第二行只放值（地址、版本号、条数、路径），用 `row_text`。
- 首次引导是例外：说明写在名称下面，第一次打开的人要读到它。
- 单位跟在数字后面（`number_unit`、滑条的 `unit`），名称只写这是什么量，不在括号里写单位。

## 按钮

- 对整组的操作（添加、刷新、打开文件夹、去别处编辑）放在分组标题右侧的图标工具里：`section_tools` 加 `tool`。不在块的最后一行另放文字按钮。
- 对某一行的操作（选图片、移除、恢复默认、导入、导出、复制、删除）放在行尾，用图标按钮，名称即悬浮提示。
- 页面标题右侧的操作（导入皮肤、播放示例台词、打开弹幕面板）也是图标工具。
- 推进任务的操作用文字按钮：开始、连接、登录、邀请、检查更新、下一步。一张卡里最多一个 Primary。
- 两个同样图标会分不清时（日志文件夹、数据文件夹），保留图标加文字。
- 几项里「当前用哪一个」（角色、配置方案）用行尾的圆形标记：选中的是实心对勾，其余点一下切换。

## 图标

一个动作只用一个图标：

| 动作 | 图标（Tabler） |
|---|---|
| 添加、新建 | `PLUS` |
| 删除 | `TRASH` |
| 移除、取消 | `X` |
| 清空内容 | `ERASER` |
| 去别处编辑 | `EDIT` |
| 选一个文件（打开选择器） | `FOLDER_OPEN` |
| 在系统里打开文件夹 | `FOLDER` |
| 导入 | `DOWNLOAD` |
| 导出 | `UPLOAD` |
| 从网上下载 | `CLOUD_DOWNLOAD` |
| 刷新、重试、重新生成 | `REFRESH` |
| 恢复默认 | `RESTORE` |
| 撤回到上一步 | `ARROW_BACK_UP` |
| 播放、试听 | `PLAYER_PLAY` |
| 复制 | `COPY` |
| 打开链接 | `EXTERNAL_LINK` |
| 切换到这一项 | `CIRCLE` / `CIRCLE_CHECK` |

## 分组

- 页面中间的每一组都有标题；只有页面最前、讲的正是页面名那件事的组可以不带标题。
- 空列表是块里的一句灰字，添加的入口在标题工具里。
