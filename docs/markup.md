# 台词标记

标记写在输入框的编辑区里，工具栏按钮会替你插入。解析永不失败：认不出的标签原样显示为文字，并在状态栏提示。`[[` 表示一个字面的 `[`。

## 样式（成对使用）

| 标记 | 效果 |
| --- | --- |
| `[b]…[/b]` `[i]…[/i]` `[u]…[/u]` `[s]…[/s]` | 粗体、斜体、下划线、删除线；`[b=0]` 取消皮肤默认的粗体 |
| `[color=#e86a92]…[/color]` | 文字颜色，`#rgb` `#rrggbb` `#rrggbbaa` |
| `[size=1.5]…[/size]` `[size=32px]…[/size]` | 字号：皮肤字号的倍数，或像素 |
| `[align=center]…[/align]` | 段落对齐：`start` / `center` / `end`，支持空段；无标记时跟随皮肤 |
| `[font=accent]…[/font]` `[font="Noto Serif SC"]…[/font]` | 皮肤字体槽（body / name / accent）或指定字体族 |
| `[stroke=#ffffff,2]…[/stroke]` | 描边：颜色，宽度 |
| `[shadow=#000000aa,2,2,4]…[/shadow]` | 阴影：颜色，x，y，模糊 |
| `[ruby=かんじ]漢字[/ruby]` | 注音 |

## 逐字动效（成对使用）

| 标记 | 效果 |
| --- | --- |
| `[shake]` `[wave]` `[jump]` `[rainbow]` `[pulse]` `[flicker]` | 抖动、波浪、跳跃、彩虹、脉动、闪烁；可带 `amp=` 与 `speed=`（皮肤默认值的倍数） |
| `[fade]` `[pop]` `[slide]` | 出场：淡入、弹出、上浮；`[pop=120]` 指定毫秒 |


持续动效可以嵌套组合，例如 `[wave][rainbow]波浪彩虹[/rainbow][/wave]`。同一段保留全部效果；`amp=0` 关闭对应效果，减少动态效果模式关闭全部持续效果。

## 节奏

| 标记 | 效果 |
| --- | --- |
| `[speed=0.5]…[/speed]` | 局部变速：倍数（0.5 为两倍速） |
| `[speed=40ms]…[/speed]` | 每字固定毫秒 |
| `[instant]…[/instant]` | 整段瞬间出现 |
| `[wait=500]` | 停顿 500 毫秒 |
| `[pause]` | 停下，等待继续键 |
| `[pause auto=2000]` | 停下，2 秒后自动继续 |
| `[page]` | 等待继续，然后清空展示框，从框顶接着打 |

一句话超出展示框高度时，皮肤的 `overflow` 决定怎么办（设置 → 皮肤 → 长文本 可覆盖）：`scroll` 打到框底时整体上滚一行（默认），`page` 满一页后等待继续再翻页（相当于自动插入 `[page]`），`clip` 直接裁掉。

## 音效、表情与画面

| 标记 | 效果 |
| --- | --- |
| `[se=coin]` `[se=coin vol=0.6]` | 播放皮肤中名为 `coin` 的音效 |
| `[expr=smile]` | 触发表情：切换同名立绘差分，并发往 VTube Studio / OSC / WebSocket。在 VTube Studio 中开启同名（或在设置中映射的）热键对应的表情 |
| `[portrait=happy]` | 只切换立绘差分 |
| `[screenshake=6,300]` | 展示框震动：幅度，毫秒 |
| `[sticker=cats/hello h=1.6]` | 插入贴纸库 `cats` 中的 `hello`，高度为 1.6 倍字号 |
| `[emote=wave]` | 插入皮肤自带表情 `emotes/wave` |
| `[img="file:C:/pic.png" alt="图"]` | 插入图片 |
| `[at=1234 name="观众" avatar=blob:bili-face-1234]` | 提及直播间观众：显示为带头像和昵称的标签（样式见皮肤的 `[mention]`），整体算一个字；`at` 的值是 B 站 uid，可省略；`avatar` 可省略。通常由弹幕面板的「@」按钮插入；「回复」只附带原消息引用 |

## VTube Studio

以下标记都在打字到所在位置时发出；按 Skip 跳过时，跳过的部分里的标记会立即补发。

| 标记 | 效果 |
| --- | --- |
| `[vts hotkey=挥手]` | 按下当前模型的热键（名称或 ID） |
| `[vts expr=Smile.exp3.json]` | 开启表情文件 |
| `[vts expr=Smile.exp3.json active=off fade=0.3]` | 关闭表情文件，淡出 0.3 秒 |
| `[vts param=MouthSmile value=0.8 ms=1500]` | 把参数设为 0.8 并保持 1.5 秒（省略 `ms` 只设一次） |

联动设置中还可以开启口型同步（打字时驱动 `MouthOpen` 等参数，停顿时闭嘴），以及在台词离开展示框或下一句开始时复位本句开启的表情。

## 整句设置

写在最开头：

```text
[@auto=1500 after=fade delay=800 per=20]
```

- `auto`：播放完后多少毫秒自动推进到下一句（排队模式下）。
- `after`：`hold` 保持、`fade` 渐隐（`delay` 停留毫秒，`per` 每字额外毫秒）、`clear` 直接清除。

## 快捷短语模板

快捷短语里可以用 `{{name}}`（角色名）和 `{{time}}`（当前时间）。

富文本工具栏提供段落对齐、字号和字体面板。对齐作用于光标所在或选中段落；字号可选择皮肤字号倍率（0.5–3×）或固定像素（4–400px）。字体可使用皮肤的正文、名称、强调字体槽，或输入字体族名称。面板显示当前属性；跨选区不一致时显示「混合」。

「跟随皮肤」清除对应覆盖，源码可使用 `[size=inherit]…[/size]`、`[font=inherit]…[/font]` 在外层样式中恢复继承。倍率与字体槽随皮肤变化，像素字号与指定字体族保持固定。清除格式也会恢复所涉段落的默认对齐。
