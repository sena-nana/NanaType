# OBS / Spout 输出

Windows 下展示框、伙伴展示框和历史记录可各自通过 Spout2 发送 GPU 共享纹理，OBS 用 Spout2 插件的 *Spout2 Capture* 接收。使用方法见 [README › 接入 OBS](../README.md#接入-obs)；本页说明发送端的生命周期和实测结论。

## 发送端生命周期

- **帧交接**：NanaUI 的 DX12 渲染结果经 D3D11 桥接设备复制到 Spout 共享面，使用单个共享围栏交接；前一次 release 完成前不会发出下一次 ready。同一设备代次、同一适配器上的全部输出共用一个 D3D11 设备和 immediate context，每个 sender 自己持有注册、共享面、导入纹理和围栏，销毁一路不影响另一路。
- **动态像素**：WGSL 与扫光声明像素随时间变化（NanaUI `SceneGpuRenderer::content_version`），即使正文静止，原生保留输出也不会复用旧画面。
- **快速重开（5 秒）**：关闭输出时先发送一帧透明内容并暂停该输出，保留 sender 最多 5 秒。相同名称、尺寸和 alpha 的重开复用原 sender、共享纹理池和围栏，并重新发布当前正文。改名、改尺寸或 alpha、名称被占用、设备代次变化都不复用；透明帧发布失败直接撤销 sender，避免把旧正文冻结在 OBS 中。每个输出最多一个待复用 sender，全应用最多三个；重复设置或热重载不延长期限。
- **冷重连（30 秒）**：5 秒到期后注销发送源并释放图像资源，只保留不含图像或围栏的设备；最后一个输出关闭满 30 秒后释放设备。启用输出时在应用更新阶段创建 sender，已知固定尺寸时先发布透明面，让 OBS 发现与首帧渲染并行。
- **SDK 修正**：Spout SDK 每次构造 sender 都枚举全部显示模式（单路约 20 ms）。构建时在 `OUT_DIR` 的 SDK 副本上把它替换为一次 `ENUM_CURRENT_SETTINGS` 查询，失败时回退 60 Hz；原函数变化时构建失败，要求显式审查。
- 清理沿用原有计时线程和单个清理任务，不做逐帧轮询；应用退出释放全部 sender。

## 实测结论

2026-10-17，Windows、RTX 5060、DX12、150% DPI；官方便携 OBS 32.2.2 与 OBS Spout2 Plugin 1.12.0，1920×1080 / 60 fps，Display 960×320、History 960×360 两路真实接收，三个原生窗口同时运行。只录制本地测试源，没有推流。

- **压力测试**：约 4 分钟内 24 套皮肤循环 3 轮共 79 次切换、20 次热保存（4 次非法）、隐藏窗口、尺寸交替与输出重启。5,054 次发送全部成功，围栏 pending=0，无设备丢失；OBS 渲染与编码跳帧均为 0。发送回调 CPU 中位约 0.13 ms，重建 sender 时单次最高约 90 ms，不能承诺每帧都低于 16.7 ms。
- **快速重开**：24 次 5 秒内重开全部复用原共享池；每次关闭在 OBS 中确实变为空白，恢复后不再闪空。
- **冷重连**：同口径 8 次关闭 6 秒的 OBS 画面恢复中位数（像素精度约一帧）：

| 从开启命令到 OBS 恢复 | Display | History |
| --- | ---: | ---: |
| 5 秒内快速重开 | 28.1 ms | 14.5 ms |
| 6 秒冷重连，优化前 | 178.9 ms | 119.5 ms |
| 6 秒冷重连，优化后 | 69.6 ms | 62.3 ms |
| 32 秒完全冷启动，优化后 | 93.0 ms | 93.0 ms |

- **资源回收**：重复开关期间句柄、线程和发送源注册不随次数增长，退出后不残留幽灵发送源；关闭后效果实例遮罩、参数绑定、缩放记录和编译队列归零，只保留有界的预热程序缓存（约 13.75 MiB）。

OBS 插件仍有 100 ms 发现轮询，完全回收后需重新创建设备和图像资源，因此不保证零空白。尚未覆盖数小时直播、跨适配器、驱动故障注入或其他显卡驱动；macOS Syphon 未实测。

## 调试样例

`cargo build -p nanatype --locked --example native_outputs` 构建直接委托真实 `Host` 的调试入口（仅 Windows debug / DX12），使用正式 Spout sender 并在监测线程观测共享围栏。运行前把 `NANATYPE_NATIVE_PROBE` 指向全新隔离目录；它不读取常用安装目录，观察器不进入发布版。
