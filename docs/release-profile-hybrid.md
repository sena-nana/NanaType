# 发布构建的 S/Z 混合优化实验

2026-10-18。默认 `dist` 保持纯 `s`。混合方案未裁减应用功能，但便携包仅额外缩小 **177.61 KiB（0.49%）**；部分关键场景 P95 增加，实窗／Spout 帧率尚未验证，现有证据不足以更换默认配置。

## 配置与快照

混合方案以 `s` 为基准，将网络／服务依赖图中、位于非服务直接依赖闭包之外的 **160 个包版本**设为 `z`；渲染、文字、皮肤、媒体、音频、国际化、Spout 及共享 Windows 绑定的 **359 个包实例**保留 `s`（358 组名称／版本，`dpi 0.1.2` 有 registry 和 git 两个来源）。闭包排除构建依赖及 proc-macro 边。应用 feature、字体、解码器、GPU 后端及 unwind 均保留。

两组均使用 thin LTO、单 codegen unit、静态 CRT、行号调试信息及独立 PDB。为复用隔离缓存，两组都以 `dist` 构建，混合组额外加载包覆盖配置；没有安装 `dist-hybrid` 工作区 profile。Cargo 的包覆盖和泛型实例化规则限制了冷热路径拆分精度，参见 [Cargo 官方说明](https://doc.rust-lang.org/cargo/reference/profiles.html#overrides-and-generics)。

固定源码含 25 个皮肤，NanaUI 为 `0ae9ee350adbaadf8dc5702bb943cfed75a3d150`，源码 SHA256：`f2f48e8d0ae3b8ba28543dd7ba4416e3ea6441321dfcd7cac9f75ee5bd5824bc`。临时性能入口清单已恢复并核对原始指纹。此结果不验证工作区后续更新；[纯 S/Z 对比](release-profile-performance.md)使用更早的 24 皮肤快照，绝对数值不能跨轮直接相减。

## 关键场景

Ryzen 7 5800X、RTX 5060（驱动 616.92）、Windows build 26300、Rust 1.99.0／LLVM 23.1.1；Vulkan、960×540、1× DPI，固定逻辑 CPU 0。使用预热后的系统／驱动缓存，未改时钟和电源策略。

每配置五个独立进程，顺序 S/H/H/S/S/H/H/S/S/H；每进程三组试验，每组预热 60 tick、记录 120 tick。开始前连续三秒系统 CPU ≤20%、GPU ≤10%，整次平均 CPU >25% 的尝试拒收。先取每进程三组结果的中位数，再取五进程中位数；P95 同样汇总，不是将所有帧混合计算。

CPU 耗时包括 Runtime flush、命令录制和提交，排除 GPU 等待、时间戳映射及回读。多路输出为三个场景各两个离屏目标，不含 OBS 接收端。

## 验证范围

- 完整 49 场景矩阵各运行一个进程，48 场景工作计数一致，无 shader 错误。`shader_ink_static` 的 S 首组多出 6 次绘制及 34,064 B 上传，其余试验一致；该场景标为性能不可比，针对性复测未完成。
- 皮肤及 VP9／TGS 各完成 S／混合 1／2 个进程：25 皮肤的载荷计数一致，512×512×30 帧解码的全部像素哈希一致；本地加密 P2P 各完成一个进程，双方收到 120 条有序提交。样本不足，不据此判断性能。
- 混合配置的 Bilibili、Bridge、Douyin、P2P 库测试 **49 通过、0 失败、2 忽略**，包括双端历史／重连／离开；忽略项需要真实直播环境。
- 按用户要求停止剩余采样，实窗／原生 Spout FPS、发布包启动耗时均为 **0 个样本**。未覆盖真实服务账号、WAN、OBS 接收合成录制、其他设备和操作系统。

## 数据与复现

[汇总数据](performance/2026-10-18/dist-hybrid.json)保留逐进程关键样本、计数一致性、包体积、指纹和采样范围；[实验配置](performance/2026-10-18/dist-hybrid.toml)保留 160 个包覆盖。完整原始数据、固定源码、脚本及 ZIP 留在本机被 Git 忽略的 `target/dist-hybrid-audit/`，原始报告哈希随汇总记录。

仅对本报告固定源码，可用 `cargo --config <实验配置绝对路径> build -p nanatype --profile dist --locked`，基准去掉 `--config`。两组均设置 `RUSTFLAGS=-C target-feature=+crt-static`、`CARGO_INCREMENTAL=0`、`NANATYPE_REQUIRE_RESOURCES=1`。移植到新依赖前应重查包匹配及性能路径闭包。
