# 语音输入

语音输入会把麦克风中的语音转换为台词，写入输入窗口。它与“编辑后发送”和“实时镜像”彼此独立：你可以在任意输入模式下使用语音识别。

## 快速开始

1. 在输入窗口底栏点击麦克风，或从旁边的菜单选择“开始识别”。
2. 在“设置 › 输入 › 语音”中选择识别方式、麦克风、语言和停顿时间。
3. 说话。临时结果会显示在输入窗口的状态区域，确认后的文字才会写入草稿。
4. 默认使用**手动编辑**：检查文字后按 Enter 发送。
5. 如果希望停顿后自动发送，切换到**自动发送**。

语音识别不会执行台词标记。比如说出“`[pause]`”，它会作为普通文字写入草稿。

## 选择发送方式

### 手动编辑

识别结果进入草稿，由你检查和发送。这是首次使用时的默认模式，适合专有名词较多或需要修正文案的场景。

### 自动发送

停止说话后，应用会等待默认 3 秒，再在识别完成后提交当前台词。等待时间可在设置中调整为 1–10 秒；重新说话会取消倒计时。

自动发送沿用普通发送入口，因此仍会遵守播放队列、联机权限和弹幕同步设置。如果发送被拒绝，草稿会保留，应用会暂停识别且不会自动重试。

## 什么时候会暂停

下列操作会暂停识别，并取消本条自动发送：

- 键入、输入法组字、粘贴、删除、撤销或重做。
- 修改文字格式、插入短语或调回历史台词。
- 切换语音设置、麦克风或识别方式。

移动光标、选择文字、切换富文本 / 源码视图不会暂停。完成编辑后，点击“继续识别”；成功手动发送后也会恢复监听。

开始识别时如果已有草稿，新的识别文字会追加到末尾，并且本条必须手动发送。停止识别会保留已经确认的文字，但不会发送当前草稿。

输入窗口失焦、隐藏或最小化后，已开启的识别仍会继续。托盘图标会显示状态；暂停、停止、设备错误和退出应用都会释放麦克风。应用重启后不会自动打开麦克风。

## 选择识别方式

“系统优先”会先尝试系统支持的语言，无法使用时再使用已安装的本地模型。也可以在设置中明确选择系统或本地。

| 方式 | 说明 |
| --- | --- |
| macOS 系统识别 | 使用系统 Speech 框架。首次使用需在系统设置中允许麦克风和语音识别；系统支持设备端识别时会优先在设备上处理，其他情况可能使用 Apple 的联网服务。 |
| Windows 系统识别 | 使用桌面 SAPI 已安装的识别引擎，不需要 MSIX。可用语言取决于系统已安装的引擎；麦克风不可用时检查桌面应用麦克风权限和设备连接。 |
| 本地模型 | 使用 Whisper base 多语言 Q5_1，文件大小 59,707,625 字节，CPU 推理。安装后音频不离开设备；自动语言检测也只在本地进行。 |

默认识别语言跟随界面语言。识别后端出错时不会自动切换到另一后端，以免出现重复或混入结果；草稿会保留，你可以更改识别方式后继续。

## 安装本地模型

在“设置 › 输入 › 语音”中点击“下载 / 重试”，也可以选择“导入模型文件…”安装从上游获取的同一文件。

- 下载和导入都支持取消；进行中的安装完成前不能开始另一项安装。
- 应用会先写入临时文件，校验通过后才安装；其他模型或损坏文件会被拒绝。
- 安装文件保存在应用数据目录的 `speech/ggml-base-q5_1.bin`。
- 上游文件：[ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-base-q5_1.bin)
- SHA-256：`422f1ae452ade6f30a004d7e5c6a43195e4433bc370bf23fac9cc591f01a8898`

请只从可信来源获取模型文件，并在手动导入前核对 SHA-256。模型许可随应用打包，详见 `THIRD_PARTY_NOTICES.md`。

## 隐私与权限

- NanaType 不保存麦克风录音。
- 识别正文不会写入诊断日志。
- 使用系统识别时，是否联网由操作系统和系统识别服务决定。
- 使用本地模型时，音频只在本机处理。
- 麦克风和语音识别权限由系统设置管理；拒绝权限不会影响普通文字输入。

## 遇到问题时

- **没有识别结果**：检查麦克风权限、输入设备和系统语言是否已安装。
- **自动发送太快或太慢**：调整“停顿后发送”时间；编辑或重新说话会取消当前倒计时。
- **识别文字重复**：先停止本次识别，确认草稿后再切换识别方式；应用不会在错误后自动混用两个后端。
- **本地模型无法安装**：重新下载，或检查文件大小和 SHA-256 是否匹配。
- **需要暂时停止**：点击麦克风或托盘中的停止入口；已确认的文字会保留。
