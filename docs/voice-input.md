# 语音输入

输入窗底栏的麦克风开启／停止语音输入，旁边的菜单可以切换模式、继续识别和打开设置。**设置 › 输入 › 语音输入**集中配置识别方式、麦克风、语言和停顿秒数，并管理本地模型。

语音模式与原有的“编辑后发送／实时镜像”独立：

- **手动编辑**（首次默认）：确认的识别文字进入草稿，由用户发送。
- **自动发送**：停止说话后默认等待 3 秒（可设置为 1–10 秒），且识别已完成，才提交当前台词。重新说话取消倒计时。

键入、输入法组字、粘贴、删除、撤销／重做、格式操作、短语插入或调回历史台词都会暂停识别，取消本条自动发送。成功手动发送后恢复监听；清空或保留草稿时也可以点击“继续识别”。单纯移动光标、选择文字和切换富文本／源码视图不暂停。

开始时若已有草稿，语音结果追加到末尾，本条必须手动发送。切换识别设置也会暂停，当前草稿先手动确认。临时识别结果显示在输入窗状态区域，确认后才写入草稿。识别文字始终按普通文字插入，读出 `[pause]` 等文本不会执行标记。

开启后，失焦、隐藏或最小化输入窗仍会持续监听。托盘显示当前状态并提供停止入口。重启应用后不会自动开启麦克风；暂停、停止、设备错误及退出应用会释放采集设备。停止保留已经确认的文字，不发送当前草稿。

自动发送通过原有发送入口，因此遵循播放队列、联机权限及已开启的弹幕同步。提交被拒绝时保留草稿并暂停，不自动重试。请根据实际需要设置弹幕同步。

## 识别方式与语言

“系统优先”首先使用系统支持的所选语言，无法使用时改用已安装的本地模型；也可以明确选择系统或本地。

- **macOS**：使用 Speech 框架 `SFSpeechRecognizer`，首次需要麦克风和语音识别权限。系统支持设备端识别时优先在设备上处理，其他情况可能使用 Apple 的联网服务。权限可以在系统设置中管理。
- **Windows**：使用桌面 SAPI 的已安装识别引擎，不要求 MSIX。可用语言由系统安装的引擎决定。缺少引擎时可选择本地模型。麦克风不可用时检查 Windows 的桌面应用麦克风权限和设备连接。
- **本地模型**：Whisper base 多语言 Q5_1，59,707,625 字节，CPU 推理，无需 Python 或外部识别进程。安装后音频不离开设备。中文、英语、日语优先列出；其他语言来自后端支持列表。自动语言检测仅使用本地模型，不执行翻译。

默认识别语言跟随界面语言。识别中发生后端错误不会直接接着使用另一后端，以免混入或重复结果；草稿保留，可更改识别方式后继续。

模型由“下载／重试”主动下载，也可通过“导入模型文件…”安装从上游获取的同一文件。支持取消和删除；下载中不允许同时开始另一项安装。文件保存在应用数据目录的 `speech/ggml-base-q5_1.bin`，下载／导入先写入临时文件，校验通过后安装。其他模型及损坏文件都会拒绝。

上游文件：[ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-base-q5_1.bin)

SHA-256：`422f1ae452ade6f30a004d7e5c6a43195e4433bc370bf23fac9cc591f01a8898`

应用不保存录音，也不向诊断日志写入识别正文。第三方许可随应用打包，见 `THIRD_PARTY_NOTICES.md`。

## 实现与验证

采集、重采样和语音活动检测独立于 UI 及本地推理线程。使用单声道 16 kHz 输入、20 ms VAD 帧、200 ms 前置音频；500 ms 静音结束一段识别，最长每 20 秒分段；本地模型在长句期间每 3 秒尝试刷新临时结果，最终结果优先于临时刷新。正常发送后复用监听与模型，通过草稿版本使旧计时任务失效。自动发送停顿独立于识别分段，按语音活动时刻计算。

启停状态由识别阶段统一推导；等待和完成的识别段共用一张有序表。模型复制时同步校验摘要，避免安装后再次回读文件；音频格式转换和单声道混音在同一遍处理中完成。

采集和推理使用有界队列；过载、设备错误和识别超时都会暂停并保留草稿。会话代次隔离旧回调；识别段按音频顺序合并并去重。输入路由提前设置编辑屏障，计时器及结果回调都要验证屏障，避免 IME 尚未提交文字时自动发送。

自动测试包括状态机、配置兼容性、模型校验、编辑键分类、正文标记转义和实际输入／设置视图。真实模型文件测试单独运行：

```sh
NANATYPE_SPEECH_FIXTURES=/absolute/fixture/directory \
  cargo test -p nanatype-speech offline_fixtures -- --ignored --nocapture
```

目录包含上述固定模型、`jfk.wav`、`zh.wav`、`ja.wav`（16 kHz、单声道 PCM16）。此测试检查实际本地解码并输出载入耗时、推理耗时和实时因子；不替代真人麦克风、权限弹窗、系统识别质量或长时间直播验收。
