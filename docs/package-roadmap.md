## 阶段 1 续做：同意会话与 Windows 验收（2026-10-19）

- 审查和确认各自携带全局唯一的请求编号，复用同一后台快照消息与完成入口，由会话状态区分阶段。内容摘要绑定完整包与依赖闭包；旧结果及其错误不会覆盖新会话。
- 新请求立即清除可信来源勾选；加载、确认期间显示状态并禁止重复提交，仍可取消。取消、禁用目标插件、刷新、成功安装或移除包都会使相应待处理会话失效。取消后重新打开相同内容也不会接收旧确认。
- 确认时重新捕获内容；脚本、资源依赖变化、签名失败或后台线程创建失败均不授予同意，清除勾选并恢复可重新审查的状态。进程启动入口独立检查同意、策略版本和内容摘要。后台审查与文件变化检查复用线程入口，错误状态统一清理。
