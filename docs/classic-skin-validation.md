顺序切换全部七套时，程序、遮罩与效果纹理缓存峰值 2.49 MiB。所有编译错误列表为空；测量帧中文字塑形总计 0 次，布局节点更新总计 0 个。每套循环及事件采样前后，程序数、遮罩数与缓存字节数保持不变；上传统计保留原始值，176 字节是每次效果绘制的固定 uniform，不是纹理重传。

七套均逐像素检查完整 16 秒周期、每套 64 帧。正文及回复引用区不变、透明度不变、周期首尾完全相同；另检查开句和换说话人在 0、125、250、500、1000、2000 ms 的阅读区域。另外十一套使用静态设计，不携带运行时 WGSL，也不请求自定义效果帧；羊皮纸等图案由离线烘焙工具生成。直播弹幕按打字状态、RPG 按等待状态取样；另逐像素确认直播完成、RPG 非等待和终端等待状态在时钟推进后保持静止。
