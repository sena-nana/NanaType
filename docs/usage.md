# 使用指南

日常操作、直播平台与 OBS 接入、联机、表情包和皮肤的完整说明。功能概览见 [README](../README.md)。

## 基本操作

1. 启动后输入框出现在屏幕下方，之后记住调整的位置和尺寸；关闭输入框会隐藏到托盘并保留草稿，F8 可再次唤出。展示框与历史记录窗口为透明叠加层。
2. 在输入框里直接输入台词，按 **Enter** 发送（Shift+Enter 换行，可在设置里改为 Ctrl+Enter）。Ctrl+↑ / ↓ 调回发过的台词，Esc 隐藏。
3. 选中文字后用工具栏（或 Ctrl+B / I / U）加粗、上色、描边、注音、加动效、调节奏；不选中时，设置作用于接下来输入的文字。停顿、翻页、音效、表情等标记以细竖线显示在文字间，不占排版宽度，所以输入框与展示框的换行完全一致。
4. 工具栏的 `</>` 按钮切换到标记源码，两边编辑的是同一份台词。
5. 全局快捷键：**F8** 唤出输入框，**F9** 继续（越过停顿 / 跳过当前段）。
6. 托盘菜单可显示 / 隐藏各窗口、锁定叠加层、切换模式与皮肤、打开设置。托盘图标本身也标出状态：镜像中带粉色圆点，展示框与历史记录都隐藏时变灰，叠加层锁定时带一把小锁。

展示框、联机伙伴展示框和历史记录窗口可左键拖动、滚轮等比缩放，并通过右键菜单关闭当前窗口、直接切换全局皮肤或打开皮肤调整、切换置顶、锁定以及恢复默认位置和尺寸。自己的展示框还可继续播放、跳过当前播放和清空展示；历史窗口可切换头像、名字、时间，并通过「清空历史记录 › 确认清空」清空本次历史（联机期间不可用）。锁定后鼠标穿透，从托盘或「设置 › 窗口」解锁。关闭窗口只隐藏，已启用的 Spout2／Syphon 输出继续运行；原生右键菜单不会进入共享纹理输出。

输入模式：

两种编辑模式均支持滚轮／触控板滚动和 PageUp／PageDown 导航，Shift 可扩展选区。右键菜单提供撤销、重做、剪切、复制、粘贴和全选；中文输入法组字时，Enter、Esc 和方向键优先交给输入法。

- **编辑后发送**：写完后发送，展示框按打字机节奏播放。
- **实时镜像**：展示框实时跟随输入，发送后台词进入历史。

### Twitch 聊天与台词发送

1. 打开 **设置 › Twitch**，填写频道名或 `https://www.twitch.tv/频道名`，开启 **接收聊天**。读取聊天不需要登录。
2. 要发送台词，点击 **使用 Twitch 登录**，打开 twitch.tv/activate 输入页面显示的代码。令牌保存在系统保护的存储中（Windows DPAPI / macOS 钥匙串）。
3. 打开 **把台词发送到 Twitch 聊天** 并确认，之后发送的台词会以你的身份发到频道。长台词按 500 字符拆分，失败时暂停队列等待重试或跳过。

协议、登录与限速细节见 [Twitch 接入说明](twitch.md)。

### 第三方弹幕：blivechat 与彗星号

打开 **设置 › 第三方弹幕**，开启后选择来源：

- **blivechat**：运行 blivechat（默认 `127.0.0.1:12450`），填写开放平台身份码并点 **保存并连接**，或改用房间号。身份码保存在系统保护的存储中（Windows DPAPI / macOS 钥匙串），不写入设置文件。
- **彗星号**：在彗星号画布中加入 NanaType 插件，把设置页显示的连接地址粘贴进插件设置即可。插件页面在 [`integrations/comet/`](../integrations/comet/)，上传方式与工作原理见 [彗星号接入说明](comet.md)。

第三方弹幕消息出现在弹幕面板，@、回复和混入历史的用法相同。没有直播间时可以用模拟服务器试用 blivechat 模式：

```bash
cargo run -p nanatype-blive --example mock_blivechat
```

彗星号模式可以用脚本代替插件页面，把样例消息推给中转（需要 Node 22+）：

```bash
node scripts/comet_publish.mjs "ws://127.0.0.1:12451/comet?token=…"
```

### 联机

1. 需要 Steam 正在运行。从输入窗口底栏打开联机入口，房主点击「创建联机」。房间最多 8 人，可以设密码；密码不会写进邀请。
2. 「邀请好友」打开 Steam 邀请。被邀请的好友不用再输入密码。复制出来的邀请给其他人时，如果房间上了锁，加入前要输入密码。
3. 「展示框」始终显示自己的内容。「联机伙伴展示框」按入座顺序给其他每人一块实时台词，并在还没人进来时提供邀请和接受状态。共享历史按房主确认的顺序包含所有人已发送的内容。各方保留各自皮肤和窗口布局；实时镜像公开正在输入的内容，编辑后发送只公开已发送内容。F9、跳过和清空展示只控制自己。
4. 历史窗口在联机期间显示本次会话的台词。联机前的历史和直播间弹幕不共享。离开后恢复本机历史；本次会话不会跨进程重启恢复。会话最多保留最近 1000 条台词，并按消息大小限制裁剪。
5. 断线时保留编辑能力，发送与手动播放控制暂停。断线会让出席位，同一个人可以在还有空位时重连，已经发出的台词还在。房主离开会结束房间。

图片、贴纸、头像、引用中的头像和当前立绘以内容哈希分发。预览经房主转发；完整图片向发布者直接获取，直连失败时再向房主要。单个资源上限 16 MiB；超限或缺失时使用占位。仅自己的台词触发本机 VTube Studio／OSC 等人物控制。

Steam 能直连时走直连，否则经 Steam 中继。直连时对端能看到网络地址。

### 接入 OBS

- **Spout2**：设置 › 输出 / OBS 打开 Spout2 输出。OBS 中安装 Spout2 插件，添加 *Spout2 Capture*，选择发送端名称（默认 `NanaType Display` / `NanaType Partner` / `NanaType History`），合成模式选 *Premultiplied Alpha*。
- **分别输出**：在设置 › 输出 / OBS 分别启用「展示框」和「展示框 · 联机伙伴」，再在 OBS 添加两个来源，分别选择 `NanaType Display`（自己）和 `NanaType Partner`（对方）。尺寸、透明度和发送端名称分别设置；启用的发送端名称须互不重复。伙伴输出只在联机期间运行；联机中隐藏窗口仍会持续输出。共享历史另选 `NanaType History`。
- **窗口捕获**：*Window Capture*，捕获方式选 *Windows 10 (1903 and up)*。
- **Syphon**（macOS）：设置 › 输出 / OBS 打开 Syphon 输出。OBS 中添加 *Syphon Client*，选择发送端名称（默认 `NanaType Display` / `NanaType Partner` / `NanaType History`），合成模式选 *Premultiplied Alpha*。也可以用 *macOS Screen Capture* 捕获展示框窗口。Spout2 仅 Windows。

关闭输出 5 秒内重开会复用原发送端，OBS 画面恢复中位约 15–30 ms；发送端生命周期与真实 OBS 实测见 [OBS / Spout 输出](obs-spout.md)。

### 角色

- 「设置 › 常规 › 角色」管理台词的说话人：每个角色有名字、头像、名牌上的名字颜色（「跟随皮肤」恢复皮肤的颜色）和可选的切换快捷键，可以添加、排序和删除，最后一个角色不能删除。名字留空则不显示名牌。旧版本的角色名与头像会自动成为第一个角色。
- 切换角色：输入框底栏的角色按钮（有两个以上角色时出现）、托盘的「角色」子菜单，或「设置 › 快捷键」里的「下一个角色」「上一个角色」和每个角色自己的快捷键。当前角色会被记住；每句台词在发送时记下说话人，之后切换或改名不会改动历史记录、已保存的记录、联机伙伴看到的台词和 `line_start` 事件里的 `speaker`。
- 「设置 › 快捷键」还可以绑定「锁定/解锁叠加层」「重播上一句」（只在展示框重新播放，不再发到直播聊天，也不新增历史记录）和「显示/隐藏历史记录」，默认都未绑定；托盘的锁定和「重播上一句」项做同样的事。

### 朗读

- 「设置 › 语音 › 朗读 › 朗读发送的台词」（默认关闭）在每句台词开始显示时，用系统自带的语音读出来：macOS 用 AVSpeechSynthesizer，Windows 用 SAPI。不下载任何东西，也不联网；更多语音在系统设置里安装，装好后点「刷新语音」。
- 朗读的是台词的文字：注音读本文，提及读观众的名字，表情包、图片和标记不读。只有表情包或标点的台词不朗读。
- 新的台词会打断正在读的那句。「跳过当前句」和「清空展示框」停止朗读，「重播上一句」再读一遍。
- 可以选「默认语音」，也可以给每个角色单独选语音（列表先显示界面语言的语音，用「语音语言」查看其他语言或全部）。「语速」「音量」对所有语音生效，「试听」播放一段示例。
- 「也朗读观众弹幕」「也朗读联动搭档的台词」默认关闭，用默认语音、排在正在读的内容之后；弹幕只读进入历史记录的那些，搭档的台词在出现时读一次。
- 朗读打开时，VTube Studio 的口型同步（以及 `speaking` 事件）跟随语音，而不是打字机。
- 开关、默认语音、语速、音量和两个选项是全局的；每个角色的语音跟着角色进入配置方案。

### 翻译字幕

- 「设置 › 联动 › 翻译字幕 › 翻译发送的台词」（默认关闭）把每句台词翻译成「翻译成」选择的语言（默认英语；列表外的语言填「其他语言代码」，如 `pt-BR`），原语言自动识别。译文到达后淡入显示在对话框正文下方，字号更小、颜色更淡，沿用皮肤的字体、描边和阴影；打字和发送从不等待翻译，新的台词开始后，旧台词迟到的译文不会出现在对话框上（仍会进入历史记录）。减少动态效果时不淡入。竖排文字不显示字幕。
- **服务**：「OpenAI 兼容」适用于 OpenAI、DeepSeek（`https://api.deepseek.com/v1`）以及本机的 Ollama（`http://localhost:11434/v1`）、LM Studio（`http://localhost:1234/v1`），填「接口地址」（写到 `/v1`）和「模型」；本机服务不需要密钥。提示词要求只输出译文、简短、保留人名，并附上说话人作为上下文。「DeepL」只需要密钥，以 `:fx` 结尾的密钥自动使用免费版接口。
- **API 密钥**保存在系统的凭据存储（Windows 凭据管理器／macOS 钥匙串）里，不写进设置文件，也不会出现在导出文件中。「代理」留空使用系统代理；本机服务总是直连。
- **翻译哪些台词**：「自己的台词」默认打开；「联机伙伴的台词」只翻译伙伴没有附带译文的台词（伙伴自己开了翻译时，对方的译文会随台词一起同步过来）；「观众弹幕」翻译进入历史记录的弹幕。
- **显示位置**：「在对话框显示」和「在历史记录显示」分别控制；保存的历史记录总会带上译文，导出的 `.txt` 把译文写在原文下一行，`.srt` 作为字幕的第二行。WebSocket／插件事件：`line_start` 在译文已知时（重播、重复的台词）带 `translation` 字段，否则译文到达时另发 `translation` 事件（`id`、`text`、`target`），OSC 发送 `/translation`。
- 最近 256 条译文保存在内存里，重播和重复的台词立即显示。请求超时 8 秒；同时等待的请求过多时，较旧的会被新台词取代。失败不会打断发送：设置页的状态标签显示原因，同类失败只提示一次（「测试」按钮可以用当前设置翻译一句示例）。
- 翻译设置是全局的，不随配置方案切换。

### 保存与搜索历史记录

- **自动保存**：发送的台词（包括联机伙伴的台词）默认按场保存到数据文件夹的 `history/`，每场一个 JSON Lines 文件（如 `2026-11-02_213005.jsonl`），逐句追加，崩溃最多丢失正在写入的一句。弹幕只有在「设置 › 历史记录 › 保存历史记录 › 同时保存弹幕」打开后才会保存，且只保存进入历史记录的弹幕，默认关闭。「保留天数」默认 30 天，启动时删除更早的记录；填 0 永久保留。「清空历史记录」只清空窗口里的历史，不删除已保存的文件。
- **查看与导出**：「设置 › 历史记录 › 已保存的记录」列出每场的开始时间和句数，「查看」显示该场的台词（时间 · 名字 · 内容），可导出 `.txt`，或导出 `.srt` 字幕（以该场第一句为 0 秒，每句显示到下一句开始或按字数估算的阅读时间）；「删除」确认后删除该场文件，「打开文件夹」打开保存位置。
- **搜索**：历史窗口未锁定时，右上角的搜索按钮展开为输入框，按内容或名字筛选（不区分大小写）；再点按钮或按 Esc 收起并清空。开启历史窗口的 Spout2／Syphon 输出时不提供搜索，输出画面始终是完整历史。

### 配置方案、导出与导入

- **配置方案**：「设置 › 常规 › 配置方案」把当前设置存为有名字的方案（如「歌回」「杂谈」），可以切换、改名、复制、用当前设置覆盖和删除。也可以从托盘的「配置方案」子菜单切换，或在「设置 › 快捷键」绑定「下一个配置方案」（按列表顺序轮换，默认未绑定）。切换时，当前方案下的改动会先存回它。方案保存在配置文件夹的 `profiles/<id>.json`，与 `settings.json` 一样原子写入。
- **方案包含什么**：角色（含头像、颜色和快捷键）与当前角色、播放、声音（输出设备除外）、皮肤与调整（设置窗口的明暗外观和热重载除外）、叠加窗口的显示、锁定、置顶与尺寸、历史窗口（保存历史记录的设置除外）、快捷短语。其余都是全局的：语言、快捷键、输入方式、联动及其地址和频道、输出、语音输入、朗读（每个角色的语音跟着角色走）、更新、开机启动、插件和窗口在屏幕上的位置。
- **导出**：「设置 › 常规 › 备份与迁移 › 导出设置」保存一个 `.json` 文件，内含应用名、设置版本、导出时间和 NanaType 版本。可选包含联动地址与频道（默认包含）、角色头像（默认包含，图片直接嵌入文件，单个超过 4 MB 或找不到的头像不包含，导出后会提示数量）和窗口位置（默认不包含，按显示器布局记录，换一台电脑多半不合适）。登录凭据和密码（Twitch、OBS、blivechat 身份码）在系统钥匙串里，从不导出；VTube Studio 插件令牌、彗星号地址令牌、代理地址里的 `用户名:密码@` 也不导出。插件授权、音频设备、GPU 和日志选项、当前方案只属于这台电脑，同样不导出。
- **导入**：「导入设置」读取导出的文件或手动复制的 `settings.json`。较旧版本的文件先按设置迁移升级；更新版本 NanaType 的文件会被拒绝。确认框列出将改变的部分，确认后才应用。导入前当前设置自动备份到 `settings.previous.json`，「恢复之前的设置」可撤销（再点一次又回到导入后的设置）。文件不含联动时保留本机的联动；本机的登录凭据始终保留。嵌入的头像写入数据文件夹的 `avatars/`。
- **全部恢复默认**：确认后把设置恢复为新安装时的样子，保留语言、首次引导完成状态和登录凭据（钥匙串中的密码不受影响，不会退出登录），同样先自动备份，可用「恢复之前的设置」撤销。窗口位置和配置方案不受影响。

### 检查更新

Steam 版由 Steam 更新，没有这一项。GitHub 版在 **设置 › 关于** 检查 GitHub Release 上的新版本，**设置 › 通用 › 更新** 默认每天自动检查一次。新版本的安装包校验通过后才会打开。下载同时尝试 GitHub 和内置代理（gh-proxy.com、ghfast.top、ghproxy.net），也可加一个自定义代理；代理只负责传输，版本清单带 Ed25519 签名，安装包按 SHA-256 校验。详见 [检查更新](updates.md)。

## 台词标记

台词以 BBCode 风格的标记保存：源码模式、快捷短语和模板都用它。完整说明见 [台词标记](markup.md)。

```text
[@auto=1500]大家好！[wait=400][b][color=#e86a92]今天[/color][/b]也来[wave]打字[/wave]啦～
[pause][shake amp=2]哇！[/shake][se=coin][expr=smile]
[ruby=かんじ]漢字[/ruby][sticker=cats/hello h=1.6]
```

## 表情包

在「设置 › 素材 › 表情包」中，可以下载「绵羊的像素头像（静态）」和「绵羊的动态表情包」预设，也可以添加本地图片文件夹、Echo-Live 根目录（包含 `res/data/emoji.js`）或 Echo-Live 表情扩展目录（包含 `main.js`）。预设只在点击时联网下载，之后与本地文件夹使用相同的导入和管理流程。

导入时会在后台准备图片、缩略图和 GIF 完整帧缓存；列表显示下载、处理、可用或失败状态。完成后可离线使用，源文件不变，未变化的内容在重启后复用缓存。修改图片或表情定义会自动重建相应缓存；移除只取消加载，不删除原文件。

在输入框表情面板中搜索名称或包名并点击插入，仍保存为 `[sticker=sp/happy h=1.35]` 或 `[sticker=sprel/laugh h=4]` 等 NanaType 标记。动态表情在预览、展示、历史和 Spout／Syphon 输出中播放；减少动态效果时显示首帧。本功能只读取 Echo-Live 的图片表情定义，不执行扩展脚本。

输入框右侧的表情包区域在底部提供「全部」和各系列子标签，表情网格单独滚动，搜索只筛选当前系列。把一个或多个文件夹拖到表情包区域或顶部的表情包标签即可快速添加；拖到标签时会自动打开该区域，导入后与设置页统一管理。

预设图片来自 [Echo-Live](https://github.com/sheep-realms/Echo-Live) 和 [绵羊动态表情包扩展](https://github.com/sheep-realms/Echo-Live-Sheep-realms-EmoteLab-Extension)，作者与图片授权显示在列表中，下载目录保留来源、定义与许可证。

「设置 › 素材 › Telegram 贴纸」可登录 Telegram 账号，使用官方搜索查找贴纸包，也可输入包名或 `https://t.me/addstickers/包名` 下载整包。首次登录需要从 [my.telegram.org](https://my.telegram.org) 获取自己的 API ID 和 API Hash，填写带国家代码的手机号，再输入收到的验证码及可选的两步验证密码。再次点击「连接 / 登录」可恢复本机会话，不必重新填写登录凭据。

下载代理支持 `socks5://127.0.0.1:7890` 和带认证的 `socks5://用户名:密码@主机:端口`；留空直连。修改后重新连接，登录、搜索、文件下载和跨数据中心连接均使用相同代理。此设置只用于 Telegram。

支持静态 WebP、TGS 矢量动画和带透明度的 VP9 WebM。下载完成后沿用本地文件夹的解析、预转码和注册流程，出现在相同的表情包列表及底部系列标签中，标识为 `tg_包名/文件ID`。动画转为 PNG 完整帧缓存，重启后可离线复用；超出 Telegram 尺寸、时长或当前渲染器支持范围的动画会明确报错。原始文件及来源保留，贴纸的权利仍属于各自创作者。

API Hash、手机号、验证码及密码只在登录期间使用，不写入配置。授权会话单独保存在应用数据目录的 `telegram.session` 中，Windows 使用当前用户的 DPAPI 加密，其他平台使用仅当前用户可读写的文件权限；请勿共享该会话文件。「退出登录并清除会话」会注销并删除本机会话，已下载的贴纸仍可离线使用。

## 皮肤

皮肤是一个含 `skin.toml` 的文件夹或 `.ntpkg` 压缩包，可继承内置皮肤只写差异。格式见 [皮肤格式](skins.md)。

音效包是含 `sounds.toml` 的包，在 **设置 › 播放 › 音效包** 中选择后，替换皮肤自带的打字音、开场与继续音效，其余音效仍由皮肤提供，见 [音效包](skins.md#音效包)。
