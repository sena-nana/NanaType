# 使用指南

这份指南按“我要做什么”组织。第一次使用只需看前两节；接入服务时，再打开对应的专题说明。

## 先完成第一次播放

1. 启动 NanaType。输入框通常出现在屏幕下方，展示框和历史记录窗口是透明叠加层。
2. 在输入框输入台词，按 **Enter** 发送；按 **Shift+Enter** 换行。
3. 展示框会逐字播放。按 **F9** 越过停顿或跳过当前段。
4. 关闭输入框只会隐藏窗口，草稿仍会保留；按 **F8** 再次唤出。

### 两种输入模式

- **编辑后发送**：写完再发送，适合需要检查台词的场景。
- **实时镜像**：展示框跟随输入，适合边写边播；发送后仍会进入历史记录。

工具栏可以修改选中文字的粗细、颜色、描边、注音、动效和节奏。工具栏上的 `</>` 可切换标记源码；两种模式编辑的是同一份台词。

## 调整窗口与皮肤

- 拖动展示框、联机伙伴窗口或历史窗口改变位置。
- 滚轮缩放窗口；右键菜单可以切换置顶、锁定和恢复默认尺寸。
- 锁定后鼠标会穿透窗口；从托盘菜单或“设置 › 窗口”解锁。
- 托盘菜单可以显示或隐藏窗口、切换模式、打开设置和切换皮肤。
- 在“设置 › 皮肤”中选择内置皮肤；皮肤制作见[皮肤格式](skins.md)。

## 接入 OBS

### 推荐：Spout2 或 Syphon

1. 在“设置 › 输出 / OBS”中打开对应输出。
2. Windows 的 OBS 添加 *Spout2 Capture*；macOS 添加 *Syphon Client*。
3. 选择发送端 `NanaType Display`，合成模式使用 *Premultiplied Alpha*。

自己的展示框、联机伙伴和历史记录可以分别输出：

- `NanaType Display`
- `NanaType Partner 1` 至 `NanaType Partner 7`
- `NanaType History`

Windows 也可以使用 *Window Capture*，捕获方式选择 *Windows 10 (1903 and up)*。完整的输出说明和常见问题见[OBS / Spout 输出](obs-spout.md)。

## 联机

1. 确认 Steam 正在运行，在输入窗口底栏选择“联机”。
2. 房主点击“创建联机”，可选设置密码；房间最多 8 人。
3. 通过“邀请好友”发送 Steam 邀请。直接复制邀请时，受密码保护的房间仍会要求输入密码。
4. 每位成员都有自己的伙伴展示框；共享历史会按房主确认的顺序显示所有已发送台词。

联机规则：

- 实时镜像会公开正在输入的内容；编辑后发送只公开已发送的台词。
- F9、跳过和清空展示只影响自己的展示框。
- 断线时仍可编辑；发送和手动播放会暂时暂停，重新加入后可继续。
- 房主离开会结束房间；离开后恢复本机历史记录。

## 聊天与弹幕

### Twitch

在“设置 › Twitch”中：

- 填写频道名或频道 URL，打开“接收聊天”即可读取消息，无需登录。
- 若要发送台词，点击“使用 Twitch 登录”，再在 Twitch 激活页输入应用显示的代码。
- 打开“把台词发送到 Twitch 聊天”后，发送的台词会以你的身份发出。

登录凭据由系统安全存储保管。协议、限速和失败重试见[Twitch 接入说明](twitch.md)。

### 第三方弹幕

在“设置 › 第三方弹幕”中选择来源：

- **blivechat**：运行 blivechat，填写身份码或房间号，点击“保存并连接”。默认地址为 `127.0.0.1:12450`。
- **彗星号**：先打开彗星号并开始监听直播间，NanaType 默认连接端口 `19400`。
- **LAPLACE Event Bridge**：按[LAPLACE 接入说明](laplace.md)填写身份码和连接地址。

消息会出现在弹幕面板，可 @、回复，也可以按设置混入历史记录。详细协议说明见[彗星号](comet.md)和[LAPLACE](laplace.md)。

## 语音、朗读与翻译

- **语音输入**：在“设置 › 语音输入”中选择系统识别或离线模型；停顿后可自动发送。见[语音输入](voice-input.md)。
- **朗读**：在“设置 › 语音 › 朗读”中选择默认语音、语速和音量，也可以为角色单独指定语音。
- **翻译字幕**：在“设置 › 翻译字幕”中选择服务、目标语言和显示位置。支持 OpenAI 兼容接口与 DeepL；密钥保存在系统凭据存储中，不会导出。翻译不会阻塞发送，失败时仍会正常播放原文。

减少动态效果时，打字动画和字幕淡入会相应简化。朗读、翻译和语音输入设置都是全局设置。

### 无障碍

在“设置 › 常规 › 无障碍”中可以开启高对比度、调整界面大小、跟随系统文字大小（Windows）和减少动态效果。应用窗口支持 Tab / Shift+Tab 导航，展示画面和 OBS 输出保持原皮肤样式。

## 历史记录与配置方案

### 历史记录

- 已发送台词默认按场自动保存；弹幕是否保存和保留天数可在“设置 › 历史记录”中单独设置。
- 在“设置 › 历史记录 › 已保存的记录”中查看、导出 `.txt` / `.srt` 或删除某一场。
- 历史窗口右上角可按名字或内容搜索；开启历史输出时，搜索不会改变 OBS 画面。
- “清空历史记录”只清空当前窗口，不删除已保存的文件。

### 配置方案

在“设置 › 配置与备份 › 配置方案”中，可以保存多套直播配置，例如“歌回”和“杂谈”。方案可以切换、复制、改名、覆盖或删除。

方案通常包含角色、皮肤、窗口显示状态、播放、声音和快捷短语。语言、联动地址、输出和更新等设置保持全局。

### 备份与迁移

在“设置 › 配置与备份 › 备份与迁移”中：

- **导出设置**：生成 `.json` 备份，可选择是否包含头像和窗口位置。
- **导入设置**：导入前会自动备份当前设置，并显示将要改变的内容。
- **恢复之前的设置**：撤销最近一次导入或“全部恢复默认”。

登录凭据和密码不会写入导出文件。

## 表情包与皮肤

### 表情包

在“设置 › 素材 › 表情包”中添加本地文件夹、Echo-Live 表情目录或预设包。也可以把文件夹直接拖到输入框右侧的表情包区域。

导入完成后，表情包可离线使用。GIF、WebP、TGS 和 WebM 动图会在展示框与 OBS 输出中播放；减少动态效果时显示首帧。

### Telegram 贴纸

在“设置 › 素材 › Telegram 贴纸”中登录后搜索贴纸包，或输入 `https://t.me/addstickers/包名`。API Hash、验证码和密码只在登录期间使用，不写入设置文件；登录会话保存在本机，不要分享会话文件。退出登录不会删除已下载的贴纸。

### 皮肤

皮肤可以是含 `skin.toml` 的文件夹或 `.ntpkg` 包。可以在设置中切换，也可以用独立的 [NanaType Editor](package-editor.md) 制作和预览。

## 角色、快捷键与联动

- 在“设置 › 角色”中添加、排序和删除角色；每个角色可以有名字、头像、颜色和独立快捷键。
- 发送台词时会记录当前说话人；之后改名或切换角色不会改变已有历史。
- “设置 › 快捷键”可绑定切换角色、锁定叠加层、重播上一句和显示历史记录。
- VTube Studio、OSC 和 WebSocket 会在台词播放到对应位置时收到表情、立绘和参数事件。

## 标记与快捷键速查

```text
[@auto=1500]大家好！[wait=400][b]今天[/b]也来[wave]打字[/wave]啦～
[pause][shake amp=2]哇！[/shake][se=coin][expr=smile]
```

常用快捷键：**F8** 唤出输入框，**F9** 继续，**Ctrl+↑ / ↓** 调回台词，**Esc** 隐藏输入框。完整语法见[台词标记](markup.md)。

## 遇到问题时

- **OBS 没有画面**：确认输出已打开、发送端名称唯一，并检查合成模式是否为 *Premultiplied Alpha*。
- **窗口找不到**：从托盘菜单显示窗口，或在设置中恢复默认位置和尺寸。
- **快捷键无效**：检查当前是否在中文输入法组字，或到“设置 › 快捷键”确认冲突。
- **弹幕连不上**：确认第三方客户端正在监听，并检查地址、端口和身份码。
- **需要更多信息**：先打开“设置 › 关于 › 日志”，再阅读[日志](logging.md)中的诊断说明。

## 检查更新

GitHub 版可在“设置 › 关于”手动检查，也会按设置自动检查；下载完成后会先校验版本清单和安装包。Steam 版由 Steam 管理更新，详情见[检查更新](updates.md)和[Steam 版](steam.md)。
